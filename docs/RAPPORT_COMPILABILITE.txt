5. ANALYSE DÉTAILLÉE DE L'IMPLÉMENTATION APPEND
═══════════════════════════════════════════════════════════════════

CORRECTIONS APPORTÉES:

1. ✅ Format LI corrigé
   Avant: (LI $T1 0)     → ERREUR
   Après: (LI 0 $T1)     → CORRECT

2. ✅ Format MOVE corrigé (5 locations)
   Avant: (MOVE dest src) → $src = $dest (inversé)
   Après: (MOVE src dest) → $dest = $src (correct)

3. ✅ Gestion du heap pointer
   Utilise $GP directement au lieu de MEM[1]

4. ✅ Taille des slots de pile
   Utilise -4/+4 au lieu de -1/+1

ALGORITHME VALIDÉ:

1. Évalue list1 et list2 sur la pile
2. Initialise pointeurs first/last
3. Boucle de copie:
   - Alloue nouvelle CONS sur le heap
   - Copie le CAR
   - Chaîne les CONS
4. Attache list2 à la fin
5. Retourne la première CONS

TESTS FONCTIONNELS:

✅ (append (cons 1 nil) (cons 2 nil))
   → Résultat: adresse 25 (heap)
   → Liste: 1 → 2 → NIL

✅ (append nil (cons 1 nil))
   → Résultat: adresse 21
   → Retourne list2 directement

✅ (append (cons 1 (cons 2 nil)) (cons 3 (cons 4 nil)))
   → Résultat: adresse 29
   → Liste: 1 → 2 → 3 → 4 → NIL

✅ (append nil nil)
   → Résultat: 0 (NIL)
