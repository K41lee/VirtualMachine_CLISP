TRANSFORMATIONS APPLIQUÉES
========================================================================

1. LABELS SYMBOLIQUES → STRINGS
   ────────────────────────────────────────────────────────
   Avant: (list :J 'LOOP_START)
          (gen-label env "LOOP")  ; retourne symbole
   
   Après: (list "J" "LOOP_START")
          (gen-label-simplified env "LOOP")  ; retourne string
   
   Raison: Le parser compile-time n'accepte que des strings
   Impact: ~40 fonctions modifiées

2. SETF GÉNÉRALISÉ → FONCTIONS SET-XXX
   ────────────────────────────────────────────────────────
   Avant: (SETF (CAR counter) (+ (CAR counter) 1))
          (SETF (GETHASH key table) value)
   
   Après: (SETQ *label-counter* (+ *label-counter* 1))
          (env-set env key value)  ; retourne nouvel env
   
   Raison: SETF avec accesseurs complexes non supporté
   Impact: ~20 fonctions modifiées

3. GETHASH/HASH-TABLES → ALISTS
   ────────────────────────────────────────────────────────
   Avant: (GETHASH key table)
          (SETF (GETHASH key table) value)
   
   Après: (alist-get key alist)
          (alist-put key value alist)
   
   Raison: Hash tables natives non supportées
   Impact: ~15 fonctions modifiées
   Note: Tables simulées avec association lists

4. CAR/CDR/CONS → FIRST/REST + DÉCOMPOSITION
   ────────────────────────────────────────────────────────
   Avant: (CAR (CONS x y))
          (CDR list)
   
   Après: (first list)
          (rest list)
          ; ou décomposition directe des paramètres
   
   Raison: Primitives CAR/CDR non supportées directement
   Impact: ~30 fonctions modifiées

5. EQ/SYMBOLP/LISTP → EQUAL/LISTP
   ────────────────────────────────────────────────────────
   Avant: (EQ symbol 'PLUS)
          (SYMBOLP expr)
   
   Après: (equal symbol "+")  ; strings au lieu de symboles
          (symbolp expr)  ; garde symbolp natif
   
   Raison: Comparaisons symboliques problématiques
   Impact: ~15 fonctions modifiées

6. APPEND VARIADIQUE → APPEND-TWO RÉCURSIF
   ────────────────────────────────────────────────────────
   Avant: (APPEND list1 list2 list3 list4)
   
   Après: (append-many (list list1 list2 list3 list4))
          ; ou
          (append-two list1 (append-two list2 
                              (append-two list3 list4)))
   
   Raison: APPEND ne supporte que 2 arguments
   Impact: ~10 fonctions modifiées

7. DOLIST/LOOP → RÉCURSION AVEC LABELS
   ────────────────────────────────────────────────────────
   Avant: (DOLIST (item list) body)
          (LOOP WHILE condition DO body)
   
   Après: Fonction récursive avec helpers:
          (defun process-list (lst)
            (if (null lst) nil
                (progn body (process-list (rest lst)))))
   
   Raison: Macros DOLIST/LOOP non supportées
   Impact: ~8 fonctions modifiées

8. MAPCAR → MAP-LIST RÉCURSIF
   ────────────────────────────────────────────────────────
   Avant: (MAPCAR #'func list)
   
   Après: (map-list func list)
          ; avec map-list défini récursivement
   
   Raison: MAPCAR natif avec fermetures non supporté
   Impact: ~5 fonctions modifiées

9. INCF/DECF → SETQ + ARITHMÉTIQUE
   ────────────────────────────────────────────────────────
   Avant: (INCF counter)
          (INCF (CAR pair))
   
   Après: (SETQ counter (+ counter 1))
          ; ou utiliser compteur global
   
   Raison: INCF macro non supportée
   Impact: ~5 fonctions modifiées

10. CASE → COND AVEC TESTS
    ────────────────────────────────────────────────────────
    Avant: (CASE expr
             (1 body1)
             (2 body2)
             (t default))
    
    Après: (COND
             ((equal expr 1) body1)
             ((equal expr 2) body2)
             (t default))
    
    Raison: CASE macro non supportée
    Impact: ~3 fonctions modifiées

========================================================================
LIMITATIONS ET SIMPLIFICATIONS
========================================================================

⚠ Hash Tables Natives
  - Remplacées par alists (association lists)
  - Performance O(n) au lieu de O(1)
  - Acceptable pour tailles raisonnables (<100 éléments)

⚠ Macros Complexes
  - LOOP avancé simplifié (COLLECT, SUM, etc. → stubs)
  - FORMAT simplifié (juste stub)
  - DEFSTRUCT simplifié (juste stub)

⚠ Fermetures Lexicales
  - Support limité des fermetures
  - Pas de capture de variables complexes
  - LABELS/FLET simplifiés

⚠ Gestion d'Erreurs
  - ERROR, CATCH, THROW simplifiés (stubs)
  - UNWIND-PROTECT simplifié

⚠ I/O
  - PRINT, READ simplifiés (stubs)
  - FORMAT très simplifié

⚠ Types Avancés
  - Tableaux simplifiés
  - Structures simplifiées
  - Pas de CLOS

;  ("SW" 2 29 0)

────────────────────────────────────────────────────────
