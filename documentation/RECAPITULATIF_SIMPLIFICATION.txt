========================================================================
TRANSFORMATIONS CLÉS
========================================================================

1. LABELS SYMBOLIQUES → STRINGS
   Avant : (list :J 'LOOP_START)
   Après : (list :J "LOOP_START")
   
   Impact : ~40 fonctions
   Raison : Le parser compile-time n'accepte que des strings

2. SETF GÉNÉRALISÉ → FONCTIONS SET-XXX
   Avant : (SETF (CAR counter) (+ (CAR counter) 1))
   Après : (SETQ *label-counter* (+ *label-counter* 1))
   
   Impact : ~15 fonctions
   Raison : SETF avec accesseurs non supporté

3. EQ/SYMBOLP → = AVEC IDS
   Avant : (EQ op 'PLUS)
   Après : (= op-id *plus-id*)
   
   Impact : ~20 fonctions
   Raison : Pas de prédicats symboliques

4. APPEND VARIADIQUE → RÉCURSIF BINAIRE
   Avant : (APPEND a b c)
   Après : (append-two-lists a (append-two-lists b c))
   
   Impact : ~10 fonctions
   Raison : Append ne supporte que 2 arguments

5. CAR/CDR/CONS → PARAMÈTRES SÉPARÉS
   Avant : (CAR (CONS x y))
   Après : x (passé directement) ou (first-of-pair x y)
   
   Impact : ~25 fonctions
   Raison : Pas de manipulation de listes natives

6. LOOP WHILE → RÉCURSION
   Avant : (LOOP WHILE (< x 10) DO (setq x (+ x 1)))
   Après : Fonction récursive avec labels
   
   Impact : ~5 fonctions
   Raison : LOOP non supporté par parser

NOTES TECHNIQUES
========================================================================

Constructions SUPPORTÉES par le compilateur :
  • IF, COND
  • LET, LET*
  • DEFUN
  • SETQ (simple : variables)
  • +, -, *, /, =, <, >, <=, >=, /=
  • Récursion
  • MAPCAR (simple, sans fermetures)
  • Labels strings pour branches

Constructions NON SUPPORTÉES :
  • CAR, CDR, CONS, LIST (primitives)
  • SETF (généralisé)
  • EQ, EQL, EQUAL (prédicats)
  • LISTP, SYMBOLP, INTEGERP (type checks)
  • CASE, LOOP, DOTIMES, DOLIST (macros)
  • APPEND variadique (>2 args)
  • Labels symboliques (symboles)
  • SETQ complexe ((car x) val)
  • Hash tables natives
  • Variables globales DEFVAR

Stratégies de contournement :
  1. Labels : Utiliser strings
  2. SETF : Créer fonctions set-XXX
  3. Prédicats : Utiliser IDs + =
  4. Listes : Déléguer à VM ou décomposer
  5. Macros : Expansion manuelle
  6. LOOP : Réécrire en récursion
  7. Variables globales : Refactorer en paramètres
