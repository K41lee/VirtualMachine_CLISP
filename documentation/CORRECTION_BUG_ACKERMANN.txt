═══════════════════════════════════════════════════════════════════════════
1. SYMPTÔMES DU BUG
═══════════════════════════════════════════════════════════════════════════

Tests progressifs d'Ackermann:
  ✅ ack(0, n) → Tous OK (cas de base)
  ✅ ack(1, n) → Tous OK (simple récursion)
  ❌ ack(2, 1) = 4 au lieu de 5
  ❌ ack(2, 2) = 5 au lieu de 7
  ❌ ack(3, 2) = 6 au lieu de 29

Le problème apparaît dès que m ≥ 2, c'est-à-dire avec la double récursion:
  ack(m, n) = ack(m-1, ack(m, n-1))

═══════════════════════════════════════════════════════════════════════════
2. ANALYSE DE LA CAUSE
═══════════════════════════════════════════════════════════════════════════

Code problématique dans compile-load-args:

  Pour l'appel: (ack (- m 1) (ack m (- n 1)))
  
  Séquence d'exécution AVANT la correction:
  
  1. Compiler arg1: (- m 1)
     → Résultat dans $V0
  
  2. MOVE $V0 $A0
     → $A0 = m-1 ✓
  
  3. Compiler arg2: (ack m (- n 1))
     → Ceci fait un appel récursif JAL ACK
     → Qui charge de nouveaux arguments dans $A0 et $A1
     → $A0 EST ÉCRASÉ! ✗
  
  4. MOVE $V0 $A1
     → $A1 = résultat de l'appel récursif ✓
     → mais $A0 ne contient plus m-1! ✗

Résultat: La fonction ack est appelée avec des arguments incorrects!

═══════════════════════════════════════════════════════════════════════════
3. SOLUTION IMPLÉMENTÉE
═══════════════════════════════════════════════════════════════════════════

Stratégie: SAUVEGARDER chaque argument sur la pile avant de compiler
le suivant, puis RESTAURER après.

Nouveau comportement de compile-load-args:

  Pour l'appel: (ack (- m 1) (ack m (- n 1)))
  
  Séquence d'exécution APRÈS la correction:
  
  1. Compiler arg1: (- m 1)
     → Résultat dans $V0
  
  2. MOVE $V0 $A0
     → $A0 = m-1 ✓
  
  3. ADDI $SP -4 $SP
     SW $A0 $SP 0
     → SAUVEGARDER $A0 sur la pile ← NOUVEAU!
  
  4. Compiler arg2: (ack m (- n 1))
     → Appel récursif, $A0 et $A1 écrasés
     → Pas grave, on les a sauvegardés!
  
  5. MOVE $V0 $A1
     → $A1 = résultat récursif ✓
  
  6. LW $A0 $SP 0
     ADDI $SP 4 $SP
     → RESTAURER $A0 depuis la pile ← NOUVEAU!
  
  7. JAL ACK
     → Arguments corrects: $A0 = m-1, $A1 = résultat_récursif ✓

4. CODE MODIFIÉ
═══════════════════════════════════════════════════════════════════════════

Fichier: src/compiler-simplified.lisp
Fonction: compile-load-args (lignes 827-864)

AVANT (bugué):
  (defun compile-load-args (args env index)
    (if (null args)
        nil
        (let ((arg-reg ...))
          (append-many
            (list
              (compile-expr-main (first args) env)
              (list (list :MOVE *reg-v0* arg-reg))
              (compile-load-args (cdr args) env (+ index 1)))))))

APRÈS (corrigé):
  (defun compile-load-args (args env index)
    (if (null args)
        nil
        (if (null (cdr args))
            ;; Dernier argument: pas besoin de sauvegarder
            ...
            ;; Pas le dernier: sauvegarder sur la pile
            (append-many
              (list
                (compile-expr-main (first args) env)
                (list (list :MOVE *reg-v0* arg-reg))
                ;; ↓↓↓ AJOUT ↓↓↓
                (list (list :ADDI *reg-sp* -4 *reg-sp*))
                (list (list :SW arg-reg *reg-sp* 0))
                ;; ↑↑↑ SAUVEGARDE ↑↑↑
                (compile-load-args (cdr args) env (+ index 1))
                ;; ↓↓↓ RESTAURATION ↓↓↓
                (list (list :LW arg-reg *reg-sp* 0))
                (list (list :ADDI *reg-sp* 4 *reg-sp*)))))))
                ;; ↑↑↑ AJOUT ↑↑↑

Optimisation: Le dernier argument n'est pas sauvegardé car aucun autre
argument ne sera compilé après lui.

6. EXEMPLE DE CODE ASSEMBLEUR GÉNÉRÉ
═══════════════════════════════════════════════════════════════════════════

Pour l'appel: (ack 2 1)

AVANT (incorrect):
  (LI 2 $V0)          ; arg1 = 2
  (MOVE $V0 $A0)      ; $A0 = 2
  (LI 1 $V0)          ; arg2 = 1
  (MOVE $V0 $A1)      ; $A1 = 1
  (JAL ACK)           ; ack(2, 1) - mais si arg2 était un appel,
                      ; $A0 serait écrasé!

APRÈS (correct):
  (LI 2 $V0)          ; arg1 = 2
  (MOVE $V0 $A0)      ; $A0 = 2
  (ADDI $SP -4 $SP)   ; Sauvegarder $A0
  (SW $A0 $SP 0)
  (LI 1 $V0)          ; arg2 = 1
  (MOVE $V0 $A1)      ; $A1 = 1
  (LW $A0 $SP 0)      ; Restaurer $A0
  (ADDI $SP 4 $SP)
  (JAL ACK)           ; ack(2, 1) avec $A0 et $A1 corrects ✓
