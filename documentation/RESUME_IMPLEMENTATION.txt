INNOVATIONS TECHNIQUES
═══════════════════════════════════════════════════════════════════════════════

1. Système de tags pour les nombres
   ─────────────────────────────────
   Problème: Les petits nombres (1, 2, 3...) correspondent aux IDs de symboles
             existants (LI=1, LW=2, SW=3...)
   Solution: Stocker les nombres dans *vm-lisp-objects* avec tag :NUMBER
             Format: (cons :NUMBER valeur)
             Permet de distinguer 2 (nombre) de 2 (ID du symbole LW)

2. Gestion automatique des handles
   ────────────────────────────────
   • Variable globale *vm-next-handle* initialisée à 1000
   • next-handle-for-vm() incrémente et retourne
   • Évite les conflits avec les IDs de symboles (< 100)
   • Performance O(1) au lieu de O(n) avec recherche du max

3. Reconstruction intelligente
   ───────────────────────────
   read-expression-from-vm():
   • Détecte automatiquement le type (nombre tagué, cons, symbole)
   • Convertit les IDs de symboles en keywords (:FIBO, :+, :IF)
   • Support de la profondeur maximale (protection contre boucles)
   • Validation complète de la structure

4. Construction récursive
   ──────────────────────
   build-expression-in-vm():
   • Gère atomes et listes de manière récursive
   • Support de n'importe quelle profondeur d'imbrication
   • Construit (defun fibo (n) (if...)) → ~50 objets en mémoire
   • Performance: O(n) où n = nombre de nœuds dans l'arbre
