✅ CORRECTIONS DE BUGS (100% COMPLÉTÉ)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Opcodes format mismatch
   • Problème: Compiler générait symboles, VM attendait keywords
   • Solution: Ajout dans *opcodes*, conversion cohérente

2. instruction-arity
   • Problème: Nouveaux opcodes non reconnus
   • Solution: Ajout arités pour tous les nouveaux opcodes

3. make-hash-table :test
   • Problème: VM attendait keywords, Lisp veut symboles
   • Solution: Conversion 0='eq, 1='equal → symboles Lisp

4. compile-hash-set-prim offset bug
   • Problème: Offset incorrect, table écrasée par key
   • Solution: table à $SP+4, key à $SP+0 après empilements

5. Conflits de noms
   • Problème: make-hash-table, gethash, etc. conflits avec CL
   • Solution: Préfixe vm- sur toutes les primitives

🎯 PRIORITÉ 1: DOLIST (CRITIQUE)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Nécessité: collect-labels, resolve-labels, load-code
Stratégie: Expansion en while loop

Syntaxe:
  (dolist (var list) body...)

Expansion:
  (let ((%%list%% list)
        (var nil))
    (while (vm-consp %%list%%)
      (setq var (vm-car %%list%%))
      body...
      (setq %%list%% (vm-cdr %%list%%))))

Fichier: src/compiler.lisp, fonction compile-dolist
Tests: test-dolist-basic.lisp
