1. PROBLÈME INITIAL
═══════════════════════════════════════════════════════════════════════════

Avant cette modification, les fonctions ne supportaient qu'UN SEUL paramètre:
- Seul $A0 était utilisé pour passer l'argument
- Le paramètre était stocké dans $S0
- Les tests power(base, exp) et ack(m, n) échouaient

═══════════════════════════════════════════════════════════════════════════
2. SOLUTION IMPLÉMENTÉE
═══════════════════════════════════════════════════════════════════════════

Architecture MIPS standard:
- Registres $A0-$A3: jusqu'à 4 arguments de fonction
- Stack ($SP + $FP): pour paramètres additionnels et sauvegarde
- Frame Pointer ($FP): référence fixe pour accéder aux paramètres

═══════════════════════════════════════════════════════════════════════════
3. MODIFICATIONS APPORTÉES
═══════════════════════════════════════════════════════════════════════════

3.1 compile-defun-simplified (lignes 731-764)
-------------------------------------------------
Avant:
- 1 paramètre seulement ($A0 → $S0)
- Stack: [$ RA | param]
  
Après:
- N paramètres ($A0-$A3)
- Stack via $FP: [$RA | $FP | param1 | param2 | ...]
- Ajout d'un saut (J end-label) pour éviter l'exécution accidentelle

Code généré:
  (J fn_END)              ; Skip function body
  (LABEL fn)
  (ADDI $SP -size $SP)    ; Allocate stack frame
  (SW $RA $SP 0)          ; Save return address
  (SW $FP $SP 4)          ; Save old frame pointer
  (MOVE $SP $FP)          ; Set new frame pointer
  (SW $A0 $FP 8)          ; Save param 1
  (SW $A1 $FP 12)         ; Save param 2
  ... function body ...
  (LW $FP $SP 4)          ; Restore frame pointer
  (LW $RA $SP 0)          ; Restore return address
  (ADDI $SP size $SP)     ; Deallocate frame
  (JR $RA)                ; Return
  (LABEL fn_END)
  (LI 0 $V0)              ; DEFUN returns 0

3.2 compile-funcall-simplified (lignes 803-818)
-------------------------------------------------
Avant:
- Chargeait 1 seul argument
- Sauvegardait $RA (erreur!)

Après:
- Charge N arguments dans $A0-$A3
- NE sauvegarde PAS $RA (JAL le fait automatiquement)
- Sauvegarde seulement $S0, $S4-$S6

Code généré:
  (ADDI $SP -16 $SP)      ; Save registers
  (SW $S0 $SP 0)
  (SW $S4 $SP 4)
  (SW $S5 $SP 8)
  (SW $S6 $SP 12)
  (LI arg1 $V0)           ; Load arg 1
  (MOVE $V0 $A0)          ; → $A0
  (LI arg2 $V0)           ; Load arg 2
  (MOVE $V0 $A1)          ; → $A1
  (JAL fn)                ; Call (saves $RA automatically)
  (LW $S0 $SP 0)          ; Restore registers
  (LW $S4 $SP 4)
  (LW $S5 $SP 8)
  (LW $S6 $SP 12)
  (ADDI $SP 16 $SP)

3.3 compile-variable-simplified (lignes 359-376)
-------------------------------------------------
Ajout support pour accès via $FP:

Avant:
  - :in-s0 → MOVE $S0 $V0
  - (:stack N) → LW $V0 $SP N

Après:
  - :in-s0 → MOVE $S0 $V0
  - (:frame N) → LW $V0 $FP N    ← NOUVEAU!
  - (:stack N) → LW $V0 $SP N

3.4 Fonctions auxiliaires ajoutées
-----------------------------------
- compile-save-params: Sauvegarde $A0-$A3 sur la pile via $FP
- compile-load-args: Charge arguments dans $A0-$A3 avant appel
- compile-function-body-with-multi-params: Corps de fonction multi-params
- add-params-to-env: Ajoute params à l'environnement avec offsets (:frame)

4. POURQUOI $FP (Frame Pointer) EST ESSENTIEL
═══════════════════════════════════════════════════════════════════════════

PROBLÈME avec $SP seul:
  Fonction ADD avec (+ a b):
    1. SW $A0 $SP 4    ; Save param a at $SP+4
    2. SW $A1 $SP 8    ; Save param b at $SP+8
    3. LW $V0 $SP 4    ; Load a ✓
    4. ADDI $SP -4 $SP ; Push intermediate value (MODIFIE $SP!)
    5. SW $V0 $SP 0    ; Save a
    6. LW $V0 $SP 8    ; Load b from $SP+8 ← ERREUR! $SP a changé!
  
SOLUTION avec $FP:
  $FP reste fixe pendant toute la fonction:
    1. MOVE $SP $FP    ; $FP = fixed reference
    2. SW $A0 $FP 8    ; Save param a at $FP+8
    3. SW $A1 $FP 12   ; Save param b at $FP+12
    4. LW $V0 $FP 8    ; Load a ✓
    5. ADDI $SP -4 $SP ; $SP change, mais $FP ne change pas!
    6. SW $V0 $SP 0    ; Save on stack
    7. LW $V0 $FP 12   ; Load b from $FP+12 ✓ (offset toujours valide!)

7. EXEMPLE COMPLET DE COMPILATION
═══════════════════════════════════════════════════════════════════════════

Code source:
  (progn
    (defun add (a b)
      (+ a b))
    (add 10 32))

Code MIPS généré (33 instructions):
  0: (J ADD_END)              ; Skip function definition
  1: (LABEL ADD)              ; Function entry point
  2: (ADDI $SP -16 $SP)       ; Allocate frame (8+2*4=16)
  3: (SW $RA $SP 0)           ; Save return address
  4: (SW $FP $SP 4)           ; Save frame pointer
  5: (MOVE $SP $FP)           ; Set frame pointer
  6: (SW $A0 $FP 8)           ; Save param a
  7: (SW $A1 $FP 12)          ; Save param b
  8: (LW $V0 $FP 8)           ; Load a
  9: (ADDI $SP -4 $SP)        ; Push for intermediate
 10: (SW $V0 $SP 0)           ; Save a
 11: (LW $V0 $FP 12)          ; Load b (via $FP, toujours correct!)
 12: (LW $T0 $SP 0)           ; Pop a into $T0
 13: (ADDI $SP 4 $SP)         ; Restore stack
 14: (ADD $V0 $T0 $V0)        ; a + b → $V0
 15: (LW $FP $SP 4)           ; Restore frame pointer
 16: (LW $RA $SP 0)           ; Restore return address
 17: (ADDI $SP 16 $SP)        ; Deallocate frame
 18: (JR $RA)                 ; Return
 19: (LABEL ADD_END)          ; End of function
 20: (LI 0 $V0)               ; DEFUN returns 0
 21: (ADDI $SP -16 $SP)       ; Call setup
 22: (SW $S0 $SP 0)           ; Save $S0
 23: (SW $S4 $SP 4)           ; Save $S4
 24: (SW $S5 $SP 8)           ; Save $S5
 25: (SW $S6 $SP 12)          ; Save $S6
 26: (LI 10 $V0)              ; Load arg 1 = 10
 27: (MOVE $V0 $A0)           ; → $A0
 28: (LI 32 $V0)              ; Load arg 2 = 32
 29: (MOVE $V0 $A1)           ; → $A1
 30: (JAL ADD)                ; Call ADD (saves PC+4 to $RA)
 31: (LW $S0 $SP 0)           ; Restore $S0
 32: (LW $S4 $SP 4)           ; Restore $S4
 33: (LW $S5 $SP 8)           ; Restore $S5
 34: (LW $S6 $SP 12)          ; Restore $S6
 35: (ADDI $SP 16 $SP)        ; Cleanup

Résultat: $V0 = 42 ✅
