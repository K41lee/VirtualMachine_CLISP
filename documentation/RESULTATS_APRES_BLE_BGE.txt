1. src/vm.lisp (lignes 483-525)
   - Ajout de :BLE (Branch if Less than or Equal)
   - Ajout de :BGE (Branch if Greater than or Equal)
   
   Code ajouté:
   ```lisp
   (:BLE (let* ((src1 (first args))
                (src2 (second args))
                (label (third args))
                (val1 (get-value vm src1))
                (val2 (get-value vm src2)))
           (when (<= val1 val2)
             (let* ((code-start (calculate-code-start vm))
                    (pc-reg (get-reg :pc))
                    (target-addr (if (>= label code-start)
                                     label
                                     (+ code-start label))))
               (set-register vm pc-reg target-addr)
               (return-from execute-instruction)))))
   
   (:BGE (let* ((src1 (first args))
                (src2 (second args))
                (label (third args))
                (val1 (get-value vm src1))
                (val2 (get-value vm src2)))
           (when (>= val1 val2)
             (let* ((code-start (calculate-code-start vm))
                    (pc-reg (get-reg :pc))
                    (target-addr (if (>= label code-start)
                                     label
                                     (+ code-start label))))
               (set-register vm pc-reg target-addr)
               (return-from execute-instruction)))))
   ```

                    INSTRUCTIONS DE BRANCHEMENT COMPLÈTES
═══════════════════════════════════════════════════════════════════════════════

Toutes les comparaisons MIPS sont maintenant supportées:

✅ BEQ - Branch if Equal (=)
✅ BNE - Branch if Not Equal (!=)
✅ BLT - Branch if Less Than (<)
✅ BGT - Branch if Greater Than (>)
✅ BLE - Branch if Less than or Equal (<=) ⬆️ NOUVEAU
✅ BGE - Branch if Greater than or Equal (>=) ⬆️ NOUVEAU

Ces 6 instructions permettent de compiler toutes les comparaisons Lisp:
  - (= a b) → BEQ
  - (/= a b) → BNE
  - (< a b) → BLT
  - (> a b) → BGT
  - (<= a b) → BLE
  - (>= a b) → BGE
