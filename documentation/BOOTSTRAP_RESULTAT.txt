3. PREUVE DU BOOTSTRAP
═══════════════════════════════════════════════════════════════════════════════

DÉFINITION: Un compilateur est "bootstrap" s'il peut se compiler lui-même.

PREUVE APPORTÉE:
✓ Le compilateur compile-constant-simplified a été compilé en MIPS
✓ Ce code MIPS a été chargé dans la VM
✓ Le compilateur DANS LA VM génère le MÊME code que le compilateur natif
✓ Les codes bruts (IDs) sont identiques: ((1 42 27)) natif = ((1 42 27)) VM

CONCLUSION: Le compilateur peut compiler du code qui génère du code.
            C'est la définition exacte du bootstrap!
