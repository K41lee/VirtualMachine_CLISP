================================================================================
PRINCIPALES TRANSFORMATIONS
================================================================================

1. Labels symboliques → strings
   'LOOP_START → "LOOP_START"

2. SETF généralisé → fonctions set-XXX
   (SETF (GETHASH key table) val) → (alist-put key val table)

3. Hash tables → alists
   (GETHASH key table) → (alist-get key alist)

4. CAR/CDR → FIRST/REST
   (CAR list) → (first list)

5. APPEND variadique → append-two récursif
   (APPEND a b c) → (append-many (list a b c))

6. DOLIST/LOOP → récursion avec labels
   (DOLIST (x lst) body) → fonction récursive

7. INCF → SETQ + arithmétique
   (INCF counter) → (SETQ counter (+ counter 1))

8. CASE → COND
   (CASE x ((1) a) ((2) b)) → (COND ((= x 1) a) ((= x 2) b))
