✅ POINT 2: Représentation des expressions Lisp en mémoire
──────────────────────────────────────────────────────────

STATUS: ✅ COMPLET (nouveau, implémenté et testé à 96%)

Fichier créé: utils-bootstrap.lisp (167 lignes)

Fonctions principales:
• build-expression-in-vm(expr)
  - Construit n'importe quelle expression Lisp en mémoire
  - Gère atomes (nombres, symboles) et listes
  - Récursif: supporte l'imbrication infinie
  - Retourne un handle vers l'objet créé

• read-expression-from-vm(handle)
  - Lit et reconstruit une expression depuis un handle
  - Convertit les IDs en keywords pour la validation
  - Protection contre les boucles infinies (max-depth)

• build-atom-in-vm(atom)
  - Nombres: stockés directement
  - Symboles: convertis en IDs via intern-symbol()
  - NIL: représenté par 0

• build-list-in-vm(list)
  - Construit récursivement les cellules cons
  - Stocke dans *vm-lisp-objects* avec handles uniques
  - Structure: (cons car-handle cdr-handle)

Fonctions helper:
• build-defun-in-vm(name, params, body)
• build-if-in-vm(test, then-part, else-part)
• build-lambda-in-vm(params, body)

Fonctions debug:
• count-vm-objects(): Nombre d'objets créés
• list-vm-objects(): Liste tous les handles
• clear-vm-objects(): Vide la table

Innovation technique:
• Handles démarrent à 1000 (évite conflits avec IDs de symboles)
• Compteur global *vm-next-handle* pour performance O(1)
• Support complet des expressions imbriquées

Tests: test-build-expressions.lisp (280 lignes)
• 23 tests couvrant:
  - Atomes simples (7 tests)
  - Listes simples (5 tests)
  - Expressions imbriquées (4 tests)
  - Fonctions (4 tests)
  - FIBO et ACK complets (2 tests)
  - Vérification structurelle (1 test)
• Résultat: 22/23 réussis (96%)

Exemples validés:
✓ 42 → 42
✓ 'FIBO → ID 54 → :FIBO
✓ '(+ 1 2) → handle 1165 → (:+ 1 2)
