ÉTAPE 1: COMPRENDRE DOLIST
═══════════════════════════════════════════════════════════════════

Syntaxe Common Lisp:
  (dolist (var list result-form)
    body...)

Comportement:
  • Itère sur chaque élément de list
  • À chaque itération, var contient l'élément courant
  • Exécute body pour chaque élément
  • Retourne result-form (optionnel, sinon nil)

Exemple:
  (dolist (x '(1 2 3))
    (print x))
  ; Affiche: 1 2 3

Expansion équivalente:
  (let ((%%list%% '(1 2 3))
        (x nil))
    (while (vm-consp %%list%%)
      (setq x (vm-car %%list%%))
      (print x)
      (setq %%list%% (vm-cdr %%list%%))))

(defun compile-dolist (var-spec body env)
  "Compile (dolist (var list) body...)
   Expansion en while loop avec car/cdr"
  (let* ((var (first var-spec))
         (list-expr (second var-spec))
         (temp-list (gensym "LIST"))
         (code '()))
    
    ;; 1. Compiler la liste initiale
    (setf code (append code (compile-expr list-expr env)))
    
    ;; 2. Sauvegarder dans une variable temporaire
    (let ((new-env (copy-env env)))
      ;; Allouer temp-list
      (let ((list-reg (allocate-temp-reg new-env)))
        (if list-reg
            (progn
              (setf code (append code (list (list :MOVE *reg-v0* list-reg))))
              (add-variable new-env temp-list list-reg))
            ;; Utiliser la pile si pas de registre
            (progn
              (setf code (append code 
                               (list (list :MOVE *reg-sp* *reg-fp*)
                                     (list :ADDI *reg-sp* -4 *reg-sp*)
                                     (list :SW *reg-v0* *reg-sp* 0))))
              (add-variable new-env temp-list (cons :frame -4)))))
      
      ;; 3. Labels pour la boucle
      (let ((label-start (gen-label new-env "DOLIST_START"))
            (label-end (gen-label new-env "DOLIST_END")))
        
        ;; 4. Label début
        (setf code (append code (list (list :LABEL label-start))))
        
        ;; 5. Tester si liste vide: (vm-consp temp-list)
        (setf code (append code (compile-expr temp-list new-env)))
        (setf code (append code (list (list :TYPE-CHECK 'consp *reg-v0*))))
        ;; Si 0 (pas consp), sortir
        (setf code (append code 
                         (list (list :BEQ *reg-v0* *reg-zero* label-end))))
        
        ;; 6. var = (vm-car temp-list)
        (setf code (append code (compile-expr temp-list new-env)))
        (setf code (append code (list (list :LIST-CAR *reg-v0*))))
        
        ;; Stocker dans var
        (let ((var-reg (allocate-temp-reg new-env)))
          (if var-reg
              (progn
                (setf code (append code (list (list :MOVE *reg-v0* var-reg))))
                (add-variable new-env var var-reg))
              ;; Pile
              (progn
                (setf code (append code
                                 (list (list :ADDI *reg-sp* -4 *reg-sp*)
                                       (list :SW *reg-v0* *reg-sp* 0))))
                (add-variable new-env var (cons :frame -8)))))
        
        ;; 7. Exécuter le corps
        (dolist (expr body)
          (setf code (append code (compile-expr expr new-env))))
        
        ;; 8. temp-list = (vm-cdr temp-list)
        (setf code (append code (compile-expr temp-list new-env)))
        (setf code (append code (list (list :LIST-CDR *reg-v0*))))
        ;; Mettre à jour temp-list
        (setf code (append code (compile-setq temp-list *reg-v0* new-env)))
        
        ;; 9. Retour au début
        (setf code (append code (list (list :J label-start))))
        
        ;; 10. Label fin
        (setf code (append code (list (list :LABEL label-end))))))
    
    code))

ÉTAPE 6: ALTERNATIVE SIMPLIFIÉE (SI DOLIST TROP COMPLEXE)
═══════════════════════════════════════════════════════════════════

Réécrire les fonctions du loader SANS dolist:

collect-labels SANS dolist:
  (defun collect-labels (asm-code code-start)
    (let ((labels (vm-make-hash-table :test 'equal))
          (position 0)
          (remaining asm-code))
      (while (vm-consp remaining)
        (let ((instr (vm-car remaining)))
          (if (and (vm-consp instr) 
                   (eq (vm-car instr) :LABEL))
              (vm-hash-set labels (vm-car (vm-cdr instr))
                          (+ code-start position))
              (setq position (+ position 1))))
        (setq remaining (vm-cdr remaining)))
      labels))

Avantage:
  • Pas besoin d'implémenter dolist
  • Plus simple et direct
  • Même résultat

Inconvénient:
  • Moins lisible que la version avec dolist
  • Tous les fichiers doivent être réécrits
