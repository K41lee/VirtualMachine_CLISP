NOM: compile-from-handle(handle)

FICHIER: utils-bootstrap.lisp

BUT: Compiler une expression Lisp stockée en mémoire via son handle

PIPELINE:
  Handle → read-expression-from-vm() → Expression (keywords)
         → convert-keywords-to-symbols() → Expression (symboles)
         → compile-lisp-to-mips-simplified() → Code MIPS

UTILISATION (MODE NATIF)
═══════════════════════════════════════════════════════════════════════════════

;; 1. Charger les bibliothèques
(load "src/asm-ops.lisp")
(load "src/vm.lisp")
(load "src/compiler-simplified.lisp")
(load "utils-bootstrap.lisp")

;; 2. Construire une expression en mémoire
(defparameter *expr* '(defun fibo (n)
                        (if (< n 2)
                            n
                            (+ (fibo (- n 1)) (fibo (- n 2))))))

(defparameter *handle* (build-expression-in-vm *expr*))
;; => Handle: 1027

;; 3. Compiler depuis le handle
(defparameter *code* (compile-from-handle *handle*))
;; => 79 instructions MIPS

;; 4. Vérifier que c'est identique au natif
(defparameter *code-natif* (compile-lisp-to-mips-simplified *expr*))
(equal *code* *code-natif*)
;; => T (IDENTIQUE!)

PROBLÈME:
compile-from-handle appelle d'autres fonctions Lisp:
  • read-expression-from-vm(handle)
  • convert-keywords-to-symbols(expr)
  • compile-lisp-to-mips-simplified(expr)

Ces fonctions ne sont pas disponibles comme appels directs dans la VM.

POURQUOI:
La VM exécute du code MIPS compilé. Les appels de fonction Lisp nécessitent:
  1. Un système de résolution de symboles de fonctions
  2. Une table d'adresses de fonctions
  3. Ou toutes les fonctions compilées et liées

SOLUTIONS POSSIBLES:

Option A: Utilisation en MODE NATIF (recommandé actuellement)
  ✅ Avantages:
     - Fonctionne parfaitement
     - Tests 100% réussis
     - Code identique au natif
     - Simple à utiliser
  ❌ Limitations:
     - N'est pas exécuté dans la VM

Option B: Compiler TOUTES les fonctions du compilateur (132 fonctions)
  ✅ Avantages:
     - Vrai bootstrap complet dans la VM
     - Meta-compilation possible
  ❌ Limitations:
     - Complexe (appels inter-fonctions)
     - Nécessite système de liaison
     - Estimation: 20-30 heures de travail

Option C: Créer une table d'adresses de fonctions
  ✅ Avantages:
     - Résout les appels de fonctions
     - Plus simple que Option B
  ❌ Limitations:
     - Nécessite modifications du compilateur
     - Estimation: 10-15 heures de travail
