EXEMPLE D'UTILISATION
═══════════════════════════════════════════════════════════════════════════════

```lisp
;; 1. Créer une liste avec CONS
(defun make-range (n)
  (if (= n 0)
      nil
      (cons n (make-range (- n 1)))))

(make-range 5)  ; Crée (5 4 3 2 1)

;; 2. Calculer la longueur d'une liste
(defun my-length (lst)
  (if (null lst)
      0
      (+ 1 (my-length (cdr lst)))))

(my-length (make-range 10))  ; → 10

;; 3. Somme des éléments
(defun sum-list (lst)
  (if (null lst)
      0
      (+ (car lst) (sum-list (cdr lst)))))

(sum-list (make-range 10))  ; → 55 (1+2+...+10)

;; 4. Filtrer les éléments positifs
(defun filter-pos (lst)
  (if (null lst)
      nil
      (if (> (car lst) 0)
          (cons (car lst) (filter-pos (cdr lst)))
          (filter-pos (cdr lst)))))

;; 5. Quicksort sur liste
(defun quicksort (lst)
  (if (null lst)
      nil
      (append (quicksort (filter-smaller (cdr lst) (car lst)))
              (list (car lst))
              (quicksort (filter-larger (cdr lst) (car lst))))))
```

═══════════════════════════════════════════════════════════════════════════════
LIMITATIONS ET NOTES
═══════════════════════════════════════════════════════════════════════════════

✅ **Fonctionne parfaitement**:
   - CONS, CAR, CDR
   - NULL (test de NIL)
   - Construction récursive de listes
   - Handles gérés automatiquement

⚠️ **Limitations connues**:
   - NIL/liste vide représenté par handle 0
   - Les handles sont des entiers opaques (pas d'accès direct à la structure)
   - LIST, APPEND, LENGTH non encore implémentés (mais peuvent être écrits en Lisp)
   - QUOTE fonctionne pour nombres et objets simples

⚠️ **Performance**:
   - Chaque CAR/CDR est un appel VM
   - Pas d'optimisation tail-call (pour l'instant)
   - Acceptable pour algorithmes d'apprentissage

✅ **Avantages**:
   - Délégation complète à Lisp pour la gestion mémoire
   - Pas de garbage collector à implémenter
   - Code simple et maintenable
   - Debugging facile (objets visibles dans *vm-lisp-objects*)
