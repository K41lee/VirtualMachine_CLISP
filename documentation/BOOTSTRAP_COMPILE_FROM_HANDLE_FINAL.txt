┌─────────────────────────────────────────────────────────────────────────────┐
│ 1. FONCTION compile-from-handle                                             │
└─────────────────────────────────────────────────────────────────────────────┘

Localisation: utils-bootstrap.lisp

Signature:
  (defun compile-from-handle (handle) ...)

Fonctionnement:
  1. Lit l'expression depuis *vm-lisp-objects* via le handle
     → Appel à read-expression-from-vm(handle)
  
  2. Convertit les keywords en symboles normaux
     → Les symboles sont stockés comme keywords (:DEFUN, :FIBO, etc.)
     → Le compilateur attend des symboles normaux (DEFUN, FIBO, etc.)
     → Appel à convert-keywords-to-symbols(expr)
  
  3. Compile l'expression avec le compilateur natif
     → Appel à compile-lisp-to-mips-simplified(expr)
  
  4. Retourne le code MIPS généré

Dépendances:
  • read-expression-from-vm(handle, max-depth)
  • convert-keywords-to-symbols(expr)
  • compile-lisp-to-mips-simplified(expr)

DÉMONSTRATION: CODE FIBO GÉNÉRÉ
═══════════════════════════════════════════════════════════════════════════════

Expression source:
──────────────────
(defun fibo (n)
  (if (< n 2)
      n
      (+ (fibo (- n 1)) (fibo (- n 2)))))

Code MIPS généré (extrait avec symboles lisibles):
──────────────────────────────────────────────────
  (J FIBO_END)

FIBO:
  (ADDI $SP -12 $SP)        ; Prologue: allouer frame
  (SW $RA $SP 0)            ; Sauver adresse retour
  (SW $FP $SP 4)            ; Sauver frame pointer
  (MOVE $SP $FP)            ; Nouveau frame
  (SW $A0 $FP 8)            ; Sauver argument n
  
  (LW $V0 $FP 8)            ; Charger n
  (ADDI $SP -4 $SP)         ; Empiler
  (SW $V0 $SP 0)
  (LI 2 $V0)                ; Constante 2
  (LW $T0 $SP 0)            ; Dépiler
  (ADDI $SP 4 $SP)
  (BLT $T0 $V0 CMP_TRUE_3)  ; if (n < 2)
  (LI 0 $V0)
  (JMP CMP_END_4)

CMP_TRUE_3:
  (LI 1 $V0)

CMP_END_4:
  (BEQ $V0 $ZERO ELSE_1)    ; if false → else
  (LW $V0 $FP 8)            ; then: return n
  (JMP END_2)

ELSE_1:
  ; Calcul récursif: fibo(n-1) + fibo(n-2)
  (ADDI $SP -4 $SP)
  (SW $S0 $SP 0)            ; Sauver $S0
  ...
  (JAL FIBO)                ; Appel récursif 1
  ...
  (JAL FIBO)                ; Appel récursif 2
  ...
  (ADD $V0 $T0 $V0)         ; Addition résultats

END_2:
  (LW $FP $SP 4)            ; Épilogue: restaurer
  (LW $RA $SP 0)
  (ADDI $SP 12 $SP)
  (JR $RA)                  ; Retour

FIBO_END:
  (LI 0 $V0)
