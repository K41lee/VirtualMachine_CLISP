PRIMITIVE DISPONIBLES
═══════════════════════════════════════════════════════════════════

Hash-tables:
  vm-make-hash-table :test 'equal    → Crée hash-table
  vm-gethash key table               → Lit valeur
  vm-hash-set table key value        → Écrit valeur
  vm-hash-table-count table          → Compte entrées
  vm-hash-has-key table key          → Test existence

Type checking:
  (if (vm-consp x) ...)              → Test si cons
  (if (vm-listp x) ...)              → Test si liste
  (if (vm-symbolp x) ...)            → Test si symbole

Listes:
  vm-car lst                         → Premier élément
  vm-cdr lst                         → Reste de la liste
  vm-cons car cdr                    → Crée paire
  vm-first lst                       → = vm-car
  vm-second lst                      → = (vm-car (vm-cdr lst))

Iteration:
  (dolist (var list) body...)        → Boucle sur liste


═══════════════════════════════════════════════════════════════════
CODE ADAPTÉ POUR COLLECT-LABELS
═══════════════════════════════════════════════════════════════════

Version originale (loader.lisp):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
(defun collect-labels (asm-code code-start)
  (let ((labels (make-hash-table :test 'equal))
        (position 0))
    (dolist (instr asm-code)
      (if (and (listp instr) (eq (first instr) :LABEL))
          (setf (gethash (second instr) labels) 
                (+ code-start position))
          (incf position)))
    labels))

Version adaptée (compilable):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
(defun collect-labels-vm (asm-code code-start)
  (let ((labels (vm-make-hash-table :test 'equal))
        (position 0))
    (dolist (instr asm-code)
      (if (and (vm-consp instr) 
               (eq (vm-car instr) :LABEL))
          (vm-hash-set labels 
                      (vm-car (vm-cdr instr))
                      (+ code-start position))
          (setq position (+ position 1))))
    labels))

Changements:
  make-hash-table  → vm-make-hash-table
  listp            → vm-consp
  first            → vm-car
  second           → vm-car + vm-cdr
  setf gethash     → vm-hash-set
  incf             → setq (+ position 1)

═══════════════════════════════════════════════════════════════════
PROBLÈME POTENTIEL: eq vs equal
═══════════════════════════════════════════════════════════════════

Dans le code: (eq (vm-car instr) :LABEL)

⚠️  ATTENTION: eq compare identité, pas contenu
    Pour les keywords, ça fonctionne (interned)
    Mais si vm-car retourne un handle, eq échouera

Solution possible:
  1. Utiliser equal au lieu de eq
  2. S'assurer que vm-car retourne directement les keywords
  3. Implémenter vm-eq qui gère les handles
