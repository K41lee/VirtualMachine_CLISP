AVANTAGES DU CHARGEMENT EN BLOC
═══════════════════════════════════════════════════════════════════

SIMPLICITÉ
  • 1 appel au lieu de 8 appels distincts
  • Calcul automatique des adresses
  • Code plus lisible et maintenable

EFFICACITÉ
  • Code contigu en mémoire
  • Meilleure localité du cache
  • Pas de HALT entre les fonctions

FLEXIBILITÉ
  • Retour de la map complète des adresses
  • Possibilité de charger plusieurs blocs séquentiellement
  • end-addr permet de chaîner les chargements

CODE EXEMPLE

;; AVANT (méthode manuelle)
(defparameter *f1-addr* (calculate-code-start vm))
(load-code vm *FUNCTION1-MIPS*)

(load-code vm *FUNCTION2-MIPS*)
... (répéter pour chaque fonction)

;; APRÈS (chargement en bloc)
(multiple-value-bind (base addresses code end)
    (compile-and-load-file vm "fichier.lisp")
  (format t "Loader chargé de ~A à ~A~%" base end)
  (format t "Fonction F1 à : ~A~%" (gethash 'F1 addresses))
  (format t "Fonction F2 à : ~A~%" (gethash 'F2 addresses)))
