APPROCHE : Expansion en code simple (LET, WHILE, SETQ)

  →
  (let ((i 1))
    (while (<= i 5)
      (print i)
      (setq i (+ i 1))))

═══════════════════════════════════════════════════════════════════

1. EXPANSION > COMPILATION DIRECTE
   Transformer LOOP en code simple (LET/WHILE) est beaucoup plus
   rapide que de générer du MIPS directement.

2. TESTS PROGRESSIFS
   Tester d'abord les expansions isolément (test-loop-expansion)
   puis leur exécution (test-loop-expansions-exec) donne confiance.

3. GENSYM ESSENTIEL
   Les variables temporaires avec noms uniques évitent les conflits
   dans les expansions.

4. RÉUTILISATION DU CODE EXISTANT
   WHILE déjà supporté par le compilateur, on le réutilise !
