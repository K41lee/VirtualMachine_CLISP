1. CONTEXTE ET PROBLÈME INITIAL
═══════════════════════════════════════════════════════════════════════════════

PROBLÈME DÉCOUVERT (ÉTAPE 6 Phase 1):
  - Les listes quotées étaient stockées comme S-expressions Lisp, pas en mémoire
  - CAR/CDR/NULL généraient des instructions LW qui attendaient des adresses mémoire
  - Résultat: Les fonctions retournaient leurs arguments inchangés au lieu de les traiter
  - Impact: Auto-compilation impossible pour fonctions manipulant des listes

SYMPTÔMES:
  ✗ (car '(a b c)) → (A B C) au lieu de A
  ✗ (null '(a b c)) → (A B C) au lieu de 0
  ✗ (count-elements '(a b c d e)) → (A B C D E) au lieu de 5
  ✗ Tests auto-compilation: 1/12 réussis (8.3%)

CAUSE RACINE:
  - compile-constant chargeait les listes comme valeurs immédiates (LI)
  - Pas d'allocation dans le heap
  - Pas de représentation mémoire pour cons cells

3.1. COMPILATION D'UNE LISTE QUOTÉE
───────────────────────────────────────────────────────────────────────────────

Expression: (quote (1 2 3))
            
Étapes:
1. Parser → (:constant (1 2 3))
2. compile-expr → compile-constant((1 2 3))
3. compile-constant détecte (consp (1 2 3)) → compile-quoted-list
4. compile-quoted-list génère:

   Code généré:
   ┌─────────────────────────────────────────┐
   │ ; Construire 1 (CAR)                    │
   │ LI 1, $V0                               │
   │ ADDI $SP, -4, $SP                       │
   │ SW $V0, 0($SP)         ; Sauver CAR     │
   │                                         │
   │ ; Construire (2 3) (CDR) récursivement  │
   │ ... (répéter pour 2 et 3) ...           │
   │                                         │
   │ ; Restaurer CAR                         │
   │ LW $A0, 0($SP)         ; CAR dans $A0   │
   │ ADDI $SP, 4, $SP                        │
   │ MOVE $V0, $A1          ; CDR dans $A1   │
   │                                         │
   │ ; Appeler CONS runtime                  │
   │ ADDI $SP, -4, $SP                       │
   │ SW $RA, 0($SP)         ; Sauver $RA     │
   │ JAL RUNTIME_CONS                        │
   │ LW $RA, 0($SP)         ; Restaurer $RA  │
   │ ADDI $SP, 4, $SP                        │
   │                                         │
   │ ; $V0 contient maintenant l'adresse     │
   │ ; de la cons cell en mémoire            │
   └─────────────────────────────────────────┘

3.2. FONCTION RUNTIME CONS
──────────────────────────────────────────────────────────────────────────────

Code généré:
┌──────────────────────────────────────────┐
│ RUNTIME_CONS:                            │
│   MOVE $GP, $V0      ; Adresse = heap    │
│   SW $A0, 0($GP)     ; Stocker CAR       │
│   SW $A1, 1($GP)     ; Stocker CDR       │
│   ADDI $GP, 2, $GP   ; Avancer heap      │
│   JR $RA             ; Retourner         │
└──────────────────────────────────────────┘

Résultat: $V0 contient l'adresse de la cons cell

5. LIMITATIONS ET TRAVAUX FUTURS

5.1. LIMITATIONS ACTUELLES
──────────────────────────────────────────────────────────────────────────────

A) SYMBOLES
   ────────
   Problème: Les symboles sont convertis en hash codes
   Impact:   Pas de correspondance symbole ↔ hash
   Exemple:  'foo → 12345 (hash), pas de retour possible
   
   Solution nécessaire:
   ├─ Table de symboles (interning)
   ├─ Stocker (hash, string) en mémoire
   └─ Lookup bidirectionnel

B) GARBAGE COLLECTION
   ───────────────────
   Problème: Heap avec bump allocator seulement
   Impact:   Mémoire jamais libérée
   Limite:   ~500k mots avant saturation
   
   Solution nécessaire:
   ├─ Mark & Sweep GC
   ├─ Copying GC
   └─ Reference counting

C) PERFORMANCES
   ────────────
   Problème: Allocation coûteuse (appel fonction)
   Impact:   Lent pour listes longues
   
   Solution nécessaire:
   ├─ Inline allocation dans code généré
   └─ Optimisations (list pooling, etc.)

5.2. TESTS EN ÉCHEC
──────────────────────────────────────────────────────────────────────────────

A) nth-element
   ───────────
