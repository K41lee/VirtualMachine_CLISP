⚠️  EXÉCUTION DIRECTE DU LOADER COMPILÉ

Pour exécuter les fonctions du loader compilé DANS la VM, il faudrait:

1. IMPLÉMENTER LES 16 PRIMITIVES VM EN MIPS
   
   Hash-tables (5 primitives):
   • vm-make-hash-table → créer une table de hachage
   • vm-gethash         → récupérer une valeur
   • vm-hash-set        → définir une valeur
   • vm-hash-table-count → compter les entrées
   • vm-hash-has-key    → vérifier l'existence d'une clé

   Listes (4 primitives):
   • vm-cons  → construire une paire
   • vm-car   → premier élément
   • vm-cdr   → reste de la liste
   • vm-cadr  → second élément

   Prédicats de type (5 primitives):
   • vm-listp    → teste si liste
   • vm-symbolp  → teste si symbole
   • vm-keywordp → teste si mot-clé
   • vm-consp    → teste si paire
   • vm-atom     → teste si atome

   Comparaison (1 primitive):
   • vm-equal → teste l'égalité

   Mémoire (1 primitive):
   • mem-write → écriture mémoire (déjà disponible)

2. CRÉER UN LINKER
   • Résoudre les adresses d'appel entre fonctions
   • Gérer la convention d'appel (ABI)
   • Linker les modules compilés

3. SYSTÈME DE GESTION DES HANDLES
   • Les primitives VM retournent des "handles"
   • Ces handles pointent vers des structures Lisp
   • Il faudrait un garbage collector ou un système de référence
