LIMITATIONS ET EXTENSIONS FUTURES

LIMITATION PRINCIPALE
─────────────────────
⚠️  VM sans gestion mémoire dynamique
  → Listes non stockables en mémoire
  → Impact sur auto-compilation complète
  → Solution : Implémenter heap + GC (3-4 semaines)

AUTRES LIMITATIONS MINEURES
────────────────────────────
• DEFSTRUCT délégué à l'environnement hôte
• Closures avec support limité
• Optimisations basiques seulement
• Tail-call optimization manquante

EXTENSIONS RECOMMANDÉES
───────────────────────
Court terme (1-2 semaines) :
  • Optimisations (constant folding, dead code elimination)
  • Messages d'erreur améliorés
  • Debugger basique

Moyen terme (1-2 mois) :
  • Gestion mémoire dynamique (heap + GC)
  • Closures complètes
  • Macros (DEFMACRO)
  → Permet auto-compilation complète

Long terme (3-6 mois) :
  • Optimisations avancées (tail-call, inlining)
  • Type inference
  • Backends alternatifs (x86-64, ARM, LLVM)
