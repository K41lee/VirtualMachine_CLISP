1. PROBLÈME RÉSOLU
═══════════════════════════════════════════════════════════════════════════════

AVANT (Hash basique):
─────────────────────
• Symboles convertis en hash codes simples (somme ASCII)
• Exemple: 'FOO → 12345
• Problème: Pas de correspondance bidirectionnelle
  - Impossible de retrouver "FOO" depuis 12345
  - Symboles différents peuvent avoir même hash (collisions)
  - Comparaison de symboles fragile

Code:
  (defun symbol-hash (sym)
    (let ((hash 0))
      (loop for char across (symbol-name sym) do
        (setf hash (mod (+ (* hash 31) (char-code char)) 16777216)))
      hash))

Limitations:
  ✗ Pas de lookup inverse (hash → nom)
  ✗ Collisions possibles
  ✗ Auto-compilation difficile (parser ne peut pas reconstruire symboles)

APRÈS (Interning):
──────────────────
• Table de symboles bidirectionnelle
• Exemple: 'FOO → ID 10001, 10001 → "FOO"
• Avantages:
  ✓ ID unique par symbole
  ✓ Lookup bidirectionnel (nom ↔ ID)
  ✓ Idempotent (interner 2x le même symbole → même ID)
  ✓ Comparaison rapide (= sur les IDs)

STRUCTURES DE DONNÉES

        ↕ Bidirectionnel ↕

│ ─────────────────────────────────────────────────────────   │
│   10001 → "FOO"                                             │
│   10002 → "BAR"                                             │
│   10003 → "BAZ"                                             │

└─────────────────────────────────────────────────────────────┘

│ *symbol-id-counter* (entier)                                │

│   Incrémenté à chaque nouveau symbole                       │
└─────────────────────────────────────────────────────────────┘

RANGE D'IDs
───────────
• IDs commencent à 10001
• Évitent les conflits avec:
  - Nombres directs (0-9999)
  - Handles de listes (5000-9999)
  - Handles de hash-tables (1000-4999)

3. API PUBLIQUE
═══════════════════════════════════════════════════════════════════════════════

FONCTION: intern-symbol
───────────────────────
Description: Interne un symbole et retourne son ID
Signature:   (intern-symbol name) → ID
Arguments:   name : string ou symbol
Retour:      ID numérique (>= 10001)
Propriété:   Idempotent (même nom → même ID)

Exemples:
  (intern-symbol "FOO")        → 10001
  (intern-symbol "FOO")        → 10001  ; Même ID
  (intern-symbol 'BAR)         → 10002
  (intern-symbol "BAR")        → 10002  ; Symbole = string

FONCTION: get-symbol-name
─────────────────────────
Description: Récupère le nom d'un symbole depuis son ID
Signature:   (get-symbol-name id) → string
Arguments:   id : ID numérique
Retour:      string (nom) ou NIL si inexistant

Exemples:
  (let ((id (intern-symbol "FOO")))
    (get-symbol-name id))      → "FOO"
  (get-symbol-name 99999)      → NIL

FONCTION: get-symbol-id
───────────────────────
Description: Cherche l'ID d'un symbole (sans l'interner)
Signature:   (get-symbol-id name) → ID ou NIL
Arguments:   name : string ou symbol
Retour:      ID numérique ou NIL si non interné

Exemples:
  (intern-symbol "FOO")
  (get-symbol-id "FOO")        → 10001
  (get-symbol-id "UNKNOWN")    → NIL

FONCTION: symbol-interned-p
───────────────────────────
Description: Vérifie si un symbole est interné
Signature:   (symbol-interned-p name) → boolean
Arguments:   name : string ou symbol
Retour:      T si interné, NIL sinon

Exemples:
  (intern-symbol "FOO")
  (symbol-interned-p "FOO")    → T
  (symbol-interned-p "BAR")    → NIL

FONCTION: reset-symbol-table
────────────────────────────
Description: Réinitialise la table (utile pour tests)
Signature:   (reset-symbol-table) → NIL
Effet:       Vide les tables, reset compteur à 10000

FONCTION: print-symbol-table
────────────────────────────
Description: Affiche le contenu de la table
Signature:   (print-symbol-table) → NIL
Effet:       Affiche tous les symboles internés

Exemple de sortie:
  === TABLE DE SYMBOLES ===
  Nombre de symboles: 3
  
  Symboles internés:
    10001 → FOO
    10002 → BAR
    10003 → BAZ
  
  =========================

FONCTION: get-all-symbols
─────────────────────────
Description: Retourne tous les symboles sous forme de liste
Signature:   (get-all-symbols) → ((name . id) ...)
Retour:      Liste triée par ID

Exemple:
  (get-all-symbols)  → (("FOO" . 10001) ("BAR" . 10002))

COMPILE-CONSTANT (src/compiler.lisp, ligne ~880)
────────────────────────────────────────────────

AVANT:
  (defun compile-constant (value env)
    (cond
      ...
      ;; Nombre ou symbole : utiliser LI standard
      (t
       (list (list :LI value result-reg)))))

Problème: Les symboles Lisp (ex: 'FOO) étaient passés directement
          à LI, causant des erreurs ou des hash non-reproductibles.

APRÈS:
  (defun compile-constant (value env)
    (cond
      ...
      ;; Symbole : utiliser l'interning pour obtenir un ID unique
      ((symbolp value)
       (let ((symbol-id (intern-symbol value)))
         (list (list :LI symbol-id result-reg))))
      
      ;; Nombre : utiliser LI standard
      (t
       (list (list :LI value result-reg)))))

Effet: Les symboles sont maintenant internés et leurs IDs uniques
       sont utilisés dans le code compilé.

COMPILE-QUOTED-LIST (src/list-runtime.lisp, ligne ~40)
──────────────────────────────────────────────────────

AVANT:
  ;; Symbole : pour l'instant, générer un hash code
  ;; TODO: Implémenter une vraie table de symboles
  ((symbolp list)
   (let ((hash (symbol-hash list)))
     (list (list :LI hash *reg-v0*))))

APRÈS:
  ;; Symbole : utiliser l'interning
  ((symbolp list)
   (let ((symbol-id (intern-symbol list)))
     (list (list :LI symbol-id *reg-v0*))))

Effet: Les symboles dans les listes quotées utilisent aussi l'interning.

7. AVANTAGES POUR L'AUTO-COMPILATION
═══════════════════════════════════════════════════════════════════════════════

AVANT (sans interning):
───────────────────────
Problème avec le parser:
  • Le parser lit "(defun foo ...)" depuis le code source
  • Le symbole 'defun est converti en hash: 12345
  • Plus tard, le dispatcher doit reconnaître "defun"
  • Impossible car on ne peut pas retrouver "defun" depuis 12345

Exemple:
  Source: "(defun foo () 42)"
  Parsé:  (12345 67890 () 42)  ; Hash codes
  Dispatcher: (case (car expr)   ; car = 12345
                (???? ...)       ; Comment tester contre 'defun ?
                                 ; On ne connaît pas le hash de 'defun

APRÈS (avec interning):
───────────────────────
Solution:
  • Pré-interner les symboles clés: defun, if, let, etc.
  • Le parser les retrouve par leur ID
  • Le dispatcher peut comparer les IDs

Exemple:
  ; Initialisation
  (defparameter *defun-id* (intern-symbol "DEFUN"))
  (defparameter *if-id*    (intern-symbol "IF"))
  
  ; Parser
  Source: "(defun foo () 42)"
  Parsé:  (10001 10010 () 42)  ; IDs internés
  
  ; Dispatcher
  (let ((head (car expr)))  ; head = 10001
    (cond
      ((= head *defun-id*) (compile-defun ...))
      ((= head *if-id*)    (compile-if ...))
      ...))

Résultat: Le compilateur peut maintenant se compiler lui-même car
          il peut reconnaître les symboles clés (defun, if, let...).
