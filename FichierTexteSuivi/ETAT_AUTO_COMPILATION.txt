SOLUTION: TABLE DE SYMBOLES (SYMBOL INTERNING)
═══════════════════════════════════════════════════════════════════════════════

CONCEPT
───────

Une table de symboles maintient la correspondance:
  Symbole (string) ↔ ID numérique (interné)

Exemple:
  ┌─────────────┬────────┬──────────────┐
  │ Symbole     │ ID     │ Adresse heap │
  ├─────────────┼────────┼──────────────┤
  │ "if"        │ 1001   │ 50000        │
  │ "defun"     │ 1002   │ 50005        │
  │ "let"       │ 1003   │ 50010        │
  │ "quote"     │ 1004   │ 50015        │
  │ "+"         │ 1005   │ 50020        │
  └─────────────┴────────┴──────────────┘

En mémoire (heap):
  [50000] → 2           ; Longueur string "if"
  [50001] → 105 ('i')
  [50002] → 102 ('f')
  [50003] → 1001        ; ID du symbole

IMPLÉMENTATION NÉCESSAIRE
──────────────────────────

1. Structure en mémoire:
   ┌──────────────────────────────┐
   │ Symbol Table (hash table)     │
   │ ├─ String → ID               │
   │ └─ ID → String               │
   ├──────────────────────────────┤
   │ Symbol Heap:                  │
   │ ├─ [addr] length             │
   │ ├─ [addr+1..n] characters    │
   │ └─ [addr+n+1] ID             │
   └──────────────────────────────┘

2. Fonctions runtime:
   ├─ INTERN(string) → ID
   │  └─> Cherche ou crée symbole, retourne ID
   │
   ├─ SYMBOL-NAME(ID) → string-addr
   │  └─> Retourne adresse du string
   │
   └─ SYMBOL-EQ(ID1, ID2) → boolean
      └─> Compare deux symboles (simple =)

3. Modification du compilateur:
   ├─ compile-constant: Si symbole → INTERN au lieu de hash
   ├─ parse-lisp-expr: Utiliser SYMBOL-EQ pour dispatch
   └─ compile-expr: Comparer IDs au lieu de symboles

Tests: 1 jour
