📌 PRINCIPE : Compilateur Compilable + VM avec Primitives Lisp

  Le compilateur et le loader sont compilés en MIPS, mais :
  
  1. Fonctions numériques pures compilées
     → Calculs, offsets, génération de code numérique
     → Ent1èrement en MIPS
  
  2. Structures de données déléguées à Lisp
     → La VM MIPS s'exécute dans un environnement Lisp
     → Hash-tables, listes, symboles via primitives natives
     → Approche pragmatique et valide
  
  3. Bootstrap fonctionnel
     → Le compilateur compilé peut compiler d'autres fonctions
     → Le loader compilé peut charger du code
     → Démontrémontré avec test-autocompilation-simple.lisp
