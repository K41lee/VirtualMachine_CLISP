PRIMITIVE 1: VM-EQUAL
---------------------
Opcode: :EQUAL
Format: (EQUAL val1-reg val2-reg)
Effet:  $V0 = 1 si égaux, 0 sinon

Fonctionnalités:
  • Déréférence automatiquement les handles
  • Utilise Common Lisp equal (nombres, symboles, keywords, listes)
  • Permet de comparer avec :LABEL, :ADD, etc.

Implémentation VM (src/vm.lisp lignes ~840-850):
  (:EQUAL
   (let* ((val1-raw (get-value vm val1-reg))
          (val2-raw (get-value vm val2-reg))
          (val1 (gethash val1-raw *vm-lisp-objects* val1-raw))
          (val2 (gethash val2-raw *vm-lisp-objects* val2-raw))
          (result (if (equal val1 val2) 1 0)))
     (set-value vm :$v0 result)))

Implémentation compilateur (src/compiler.lisp):
  (defun compile-equal-prim (args env)
    ;; Compile val1 → $V0, sauvegarde sur pile
    ;; Compile val2 → $V0, déplace vers $T1
    ;; Récupère val1 dans $T0
    ;; EQUAL $T0 $T1 → $V0)

Usage dans le code compilé:
  (if (vm-equal x y)
      ... alors ...
      ... sinon ...)


PRIMITIVE 2: VM-CADR
--------------------
Opcode: :LIST-CADR
Format: (LIST-CADR list-reg)
Effet:  $V0 = cadr de la liste (second élément)

Fonctionnalités:
  • Équivalent à (car (cdr liste))
  • Retourne un handle si le résultat est liste/symbole
  • Utile pour extraire le nom d'un label: (cadr '(:LABEL LOOP_START))

Implémentation VM (src/vm.lisp lignes ~826-840):
  (:LIST-CADR
   (let* ((list-handle (get-value vm list-reg))
          (lst (gethash list-handle *vm-lisp-objects* list-handle))
          (result (cadr lst))
          (result-value (if (or (listp result) (symbolp result))
                            (create-handle result)
                            result)))
     (set-value vm :$v0 result-value)))

Implémentation compilateur (src/compiler.lisp):
  (defun compile-list-cadr-prim (args env)
    ;; Compile liste → $V0
    ;; LIST-CADR $V0 → $V0)

Usage dans le code compilé:
  (let ((label-name (vm-cadr instr)))
    ...)

LIMITATION DÉCOUVERTE
═══════════════════════════════════════════════════════════════════

PROBLÈME: Let imbriqués avec variables locales
-----------------------------------------------

Code qui échoue:
  (dolist (instr asm-code)
    (if (vm-consp instr)
        (let ((first-elem (vm-car instr)))
          (vm-hash-set labels first-elem position))))

Erreur: "HASH-SET: Handle invalide 5003"

Cause:
  Le compilateur ne gère pas correctement les variables locales
  dans un let imbriqué à l'intérieur d'un dolist. La variable
  first-elem n'est pas accessible dans le bon scope.

Solution de contournement:
  Utiliser setq au lieu de let imbriqué:
    (let ((first-elem nil))
      (dolist (instr asm-code)
        (if (vm-consp instr)
            (progn
              (setq first-elem (vm-car instr))
              (vm-hash-set labels first-elem position)))))

Impact:
  • Nécessite ajustement de collect-labels
  • Fonctionne avec setq dans scope externe
  • Alternative: résoudre le bug du compilateur (plus complexe)
