EXEMPLE 1 : &OPTIONAL
───────────────────────────────────────────────────────────────────
Entrée :
  (defun f (a &optional (b 10)) (+ a b))

Expansion :
  (defun f (a &rest __rest-args__)
    (let* ((b (if (>= (length __rest-args__) 1)
                  (nth 0 __rest-args__)
                  10)))
      (+ a b)))

Test :
  (f 5) → 15 ✅
  (f 5 3) → 8 ✅

EXEMPLE 2 : &KEY
───────────────────────────────────────────────────────────────────
Entrée :
  (defun f (a &key (x 1) (y 2)) (list a x y))

Expansion :
  (defun f (a &rest __rest-args__)
    (let* ((x (getf __rest-args__ :x 1))
           (y (getf __rest-args__ :y 2)))
      (list a x y)))

Test :
  (f 10) → (10 1 2) ✅
  (f 10 :x 5) → (10 5 2) ✅
  (f 10 :y 7 :x 5) → (10 5 7) ✅ (ordre flexible)

EXEMPLE 3 : &REST
───────────────────────────────────────────────────────────────────
Entrée :
  (defun f (a &rest r) (cons a r))

Expansion :
  (defun f (a &rest __rest-args__)
    (let* ((r __rest-args__))
      (cons a r)))

Test :
  (f 1) → (1) ✅
  (f 1 2 3 4) → (1 2 3 4) ✅

EXEMPLE 4 : COMBINAISON &OPTIONAL + &REST
───────────────────────────────────────────────────────────────────
Entrée :
  (defun f (a &optional b &rest r) (list a b r))

Expansion :
  (defun f (a &rest __rest-args__)
    (let* ((b (if (>= (length __rest-args__) 1)
                  (nth 0 __rest-args__)
                  nil))
           (r (nthcdr 1 __rest-args__)))
      (list a b r)))

Test :
  (f 1) → (1 nil ()) ✅
  (f 1 2) → (1 2 ()) ✅
  (f 1 2 3 4) → (1 2 (3 4)) ✅

APPROCHE TECHNIQUE
═══════════════════════════════════════════════════════════════════

STRATÉGIE D'EXPANSION :
  1. Parser la lambda-list pour identifier les sections
  2. Transformer en fonction avec &rest universel
  3. Générer des bindings LET* pour distribuer les arguments
  4. Pour &optional : tester la longueur et utiliser nth
  5. Pour &rest : utiliser nthcdr pour obtenir le reste
  6. Pour &key : utiliser getf pour chercher les keywords

AVANTAGES :
  ✅ Code MIPS pur (pas de primitives VM)
  ✅ Compatible avec le compilateur actuel
  ✅ Facile à déboguer (expansion visible)
  ✅ Performance acceptable

LIMITATIONS CONNUES :
  ⚠️  &optional + &key ensemble non encore implémenté
  ⚠️  (mais non utilisé dans compiler.lisp)
