BUG CORRIGÉ #7: TYPE-CHECK NE DÉRÉFÉRENÇAIT PAS LES HANDLES
═══════════════════════════════════════════════════════════════════

PROBLÈME:
---------
TYPE-CHECK recevait un handle (ex: 5001) et testait si 5001 est une liste.
Résultat: toujours faux car 5001 est un nombre, pas une liste!

La dolist ne s'exécutait jamais:
  (TYPE-CHECK consp $V0)  → $V0 contient handle 5001
  Test: (consp 5001)      → NIL (un nombre n'est pas un cons)
  (BEQ $V0 $ZERO label)   → Branche toujours (sortie immédiate)

CODE AVANT (src/vm.lisp lignes 755-768):
----------------------------------------
(:TYPE-CHECK
 (let* ((predicate (first args))
        (value-reg (second args))
        (value (get-value vm value-reg))  ← BUG: valeur brute (handle)
        (result (case predicate
                  (listp (if (listp value) 1 0))
                  (consp (if (consp value) 1 0))
                  ...)))
   (set-value vm :$v0 result)))

SOLUTION:
---------
Déréférencer le handle avant de tester le type, exactement comme LIST-CAR
et LIST-CDR le font déjà.

CODE APRÈS (src/vm.lisp lignes 755-770):
----------------------------------------
(:TYPE-CHECK
 (let* ((predicate (first args))
        (value-reg (second args))
        (value-raw (get-value vm value-reg))
        ;; Déréférencer les handles si nécessaire
        (value (gethash value-raw *vm-lisp-objects* value-raw))
        (result (case predicate
                  (listp (if (listp value) 1 0))
                  (consp (if (consp value) 1 0))
                  ...)))
   (set-value vm :$v0 result)))

IMPACT:
-------
✅ TYPE-CHECK fonctionne maintenant avec des handles de listes
✅ Dolist peut itérer sur des listes créées depuis Lisp
✅ Les prédicates testent le vrai type (liste, symbole, etc.) pas le handle

-------------------------

  (defun collect-labels-v1 (asm-code code-start)
    (let ((labels (vm-make-hash-table :test 'equal))
          (position 0))
      (dolist (instr asm-code)
        (if (vm-consp instr)
            (progn
              (vm-hash-set labels (vm-car instr) (+ code-start position))
              (setq position (+ position 1)))
            (setq position (+ position 1))))
      labels))

NOTE: Les valeurs sont des handles (5009, 5006, 5003) car vm-car retourne

🎉 SUCCÈS MAJEUR:

La correction du bug TYPE-CHECK était la dernière pièce manquante pour
permettre l'exécution de fonctions compilées utilisant dolist avec des
listes créées depuis Lisp.

Nous avons maintenant une architecture fonctionnelle où:
  • Les listes peuvent être créées en Lisp et passées au code compilé
  • Le code compilé peut itérer sur ces listes (dolist)
  • Le code compilé peut créer et remplir des hash-tables
  • Les prédicats de type fonctionnent avec handles
  • Les opérations sur listes (car, cdr, cons) fonctionnent

Cette base permet maintenant d'implémenter les fonctions du loader.lisp
complet (collect-labels, resolve-labels, load-code) et de compiler le
chargeur COMPLET (pas seulement la version simplifiée).
