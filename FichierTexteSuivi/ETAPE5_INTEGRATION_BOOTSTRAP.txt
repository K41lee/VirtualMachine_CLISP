IMPLÉMENTATION
════════════════════════════════════════════════════════════════

1. FICHIER : src/compiler-bootstrap-ids.lisp (~140 lignes)
   
   Ce fichier intègre tous les composants avec IDs :
   - Charge symbol-table.lisp (82 symboles)
   - Charge parser-with-ids.lisp (parser compilable)
   - Charge dispatcher-with-ids.lisp (dispatcher compilable)
   - Charge compiler.lisp (fonctions compile-*)
   
   FONCTIONS PRINCIPALES :
   
   compile-lisp-with-ids(expr)
     Point d'entrée principal pour compilation avec IDs
     Crée un environnement compiler-env correct
     Utilise dispatch-expr-with-ids au lieu de compile-expr
   
   compile-defun-with-ids(name params body)
     Compile une définition de fonction complète
     Gère le parsing et la compilation en une étape

2. ARCHITECTURE D'INTÉGRATION
   
   FLUX COMPLET :
   
   Expression LISP
        ↓
   [parse-lisp-expr-with-ids]
     - COND + = sur IDs d'opérateurs
     - Reconnaît DEFUN, IF, +, etc. par ID
        ↓
   AST avec keywords (:defun, :if, :arithmetic)
        ↓
   [get-parsed-type-id]
     - Convertit :defun → "DEFUN" → 10001 (ID)
     - Convertit :if → "IF" → 10007 (ID)
        ↓
   Type ID numérique
        ↓
   [compile-expr-with-ids]
     - COND + = sur type-id
     - Dispatch vers compile-defun, compile-if, etc.
        ↓
   Code ASM MIPS
     - Instructions LABEL, ADDI, SW, LW, ADD, etc.
     - Prêt pour assemblage et exécution

3. ENVIRONNEMENT DE COMPILATION
   
   Utilise make-new-compiler-env() qui crée une structure
   compiler-env avec :
   - variables : liste des variables locales
   - functions : table des fonctions définies
   - label-counter : compteur pour labels uniques
   - temp-regs-available : registres disponibles
   - stack-offset : position sur la pile
   - parent-env : portée lexicale
   
   Cette structure est correctement gérée par toutes les
   fonctions compile-* du compilateur principal.
