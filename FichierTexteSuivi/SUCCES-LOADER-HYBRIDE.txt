COMPOSANT 1: COLLECT-LABELS (COMPILÉ)
--------------------------------------
Langage: Lisp compilé en MIPS
Taille: 92 instructions
Utilise: 15 primitives (hash-tables, dolist, type-checking, listes)

Code Lisp:
  (defun collect-labels-compiled (asm-code code-start)
    (let ((labels (vm-make-hash-table :test 'equal))
          (position 0)
          (first-elem nil))
      (dolist (instr asm-code)
        (if (vm-consp instr)
            (progn
              (setq first-elem (vm-car instr))
              (vm-hash-set labels first-elem (+ code-start position))
              (setq position (+ position 1)))
            (setq position (+ position 1))))
      labels))

Primitives utilisées:
  • vm-make-hash-table : Création hash-table
  • vm-hash-set        : Stockage label→adresse
  • vm-consp           : Test si cons (instruction)
  • vm-car             : Extraction premier élément (opcode/label)
  • dolist             : Itération sur le code
  • if/progn/setq      : Contrôle de flux
  • +                  : Arithmétique (calcul position)

Retour: Handle vers hash-table contenant labels→adresses


COMPOSANT 2: RESOLVE-LABELS (NATIF)
------------------------------------
Langage: Common Lisp natif
Raison: Modification de listes complexe, mapcar

Code Lisp:
  (defun resolve-labels-native (asm-code labels-hash)
    (mapcar
     #'(lambda (instr)
         (if (consp instr)
             (mapcar
              #'(lambda (elem)
                  (if (and (numberp elem) (>= elem 5000))
                      (let ((obj (gethash elem *vm-lisp-objects* elem)))
                        (if (symbolp obj)
                            (let ((addr (gethash elem labels-hash)))
                              (if addr addr elem))
                            elem))
                      elem))
              instr)
             instr))
     asm-code))

Utilise:
  • mapcar: Transformation de liste
  • gethash: Lookup dans hash-table et objets
  • Déréférencement manuel de handles

Retour: Code avec références résolues


COMPOSANT 3: HYBRID-LOADER (ORCHESTRATEUR)
-------------------------------------------
Rôle: Combine les deux composants

Algorithme:
  1. Créer VM temporaire
  2. Charger collect-labels compilé
  3. Enregistrer asm-code comme handle
  4. Exécuter collect-labels → obtenir hash-table
  5. Appeler resolve-labels natif avec hash-table
  6. Retourner code résolu

Code:
  (defun hybrid-loader (asm-code code-start)
    (let ((vm (make-new-vm :verbose nil)))
      (load-code vm *collect-labels-mips* :verbose nil)
      (let ((func-addr (calculate-code-start vm))
            (code-handle (register-handle asm-code)))
        (execute-compiled-function vm func-addr code-handle code-start)
        (let ((labels-hash (get-result-hash-table vm)))
          (resolve-labels-native asm-code labels-hash)))))
