STRATÉGIE "DÉLÉGATION À LISP":
• Les structures de données (hash-tables, listes) sont gérées par
  le runtime Lisp via des "handles"
• Le code compilé manipule ces handles via les primitives VM
• Avantage : Permet de compiler du code complexe sans implémenter
  toutes les structures de données en MIPS
