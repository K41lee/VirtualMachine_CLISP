STRATÉGIE D'IMPLÉMENTATION
═══════════════════════════════════════════════════════════════════

APPROCHE : EXPANSION + DÉLÉGATION HYBRIDE

Option 1 : EXPANSION (Recommandée)
  • Transformer les paramètres avancés en code standard
  • (defun f (a &optional b) ...) → vérification + affectation
  • Avantages : Code MIPS standard, pas de primitives VM
  • Inconvénients : Code généré plus long

Option 2 : DÉLÉGATION À LISP
  • Créer des primitives VM pour gérer les paramètres
  • Stocker les infos de signature dans une table
  • Avantages : Simple, réutilise Lisp
  • Inconvénients : Dépendance runtime forte

CHOIX : Option 1 (EXPANSION)
  • Plus cohérent avec l'approche LOOP
  • Génère du code MIPS pur
  • Facilite le debugging

PHASE 1 : &OPTIONAL (Estimé : 3-4h)

1.1 Parser les paramètres &optional
    • Détecter le mot-clé &optional dans la liste de paramètres
    • Extraire les paramètres optionnels et leurs valeurs par défaut
    • Format : (param) ou (param default-value)

1.2 Générer le code d'expansion
    • Vérifier le nombre d'arguments fournis
    • Affecter les valeurs par défaut si manquant
    • Exemples :
      (defun f (a &optional (b 10)) body)
      →
      (defun f-internal (a b-supplied b) 
        (let ((b (if b-supplied b 10)))
          body))

1.3 Tester avec cas simples

PHASE 2 : &REST (Estimé : 2-3h)

2.1 Parser les paramètres &rest
    • Détecter le mot-clé &rest
    • Capturer le nom de la variable reste
    • Format : &rest rest-param

2.2 Générer le code d'expansion
    • Collecter tous les arguments après les requis
    • Créer une liste avec ces arguments
    • Exemples :

      (defun f-internal (a . args)

PHASE 3 : &KEY (Estimé : 4-5h)

    • Extraire les paramètres nommés et leurs valeurs par défaut
    • Format : (param) ou (param default-value)

3.2 Générer le code d'expansion
    • Parser la liste d'arguments keyword
    • Chercher :param-name dans les arguments
    • Affecter valeur trouvée ou valeur par défaut

EXEMPLES D'EXPANSION
═══════════════════════════════════════════════════════════════════

EXEMPLE 1 : &OPTIONAL
───────────────────────────────────────────────────────────────────
Entrée :
  (defun foo (a &optional (b 10) (c 20))
    (+ a b c))

Expansion :
  (defun foo (a &rest __rest__)
    (let* ((b (if (>= (length __rest__) 1)
                  (nth 0 __rest__)
                  10))
           (c (if (>= (length __rest__) 2)
                  (nth 1 __rest__)
                  20)))
      (+ a b c)))

EXEMPLE 2 : &KEY
───────────────────────────────────────────────────────────────────
Entrée :
  (defun bar (x &key (verbose nil) (show-code nil))
    (when verbose (print x)))

Expansion :
  (defun bar (x &rest __args__)
    (let* ((verbose (getf __args__ :verbose nil))
           (show-code (getf __args__ :show-code nil)))
      (when verbose (print x))))

EXEMPLE 3 : COMBINAISON
───────────────────────────────────────────────────────────────────
Entrée :
  (defun baz (a b &optional c &key (d 10))
    (list a b c d))

Expansion :
  (defun baz (a b &rest __args__)
    (let* ((c (if (and (>= (length __args__) 1)
                       (not (keywordp (nth 0 __args__))))
                  (nth 0 __args__)
                  nil))
           (__key-start__ (if c 1 0))
           (d (getf (nthcdr __key-start__ __args__) :d 10)))
      (list a b c d)))
