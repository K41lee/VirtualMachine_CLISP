PHASE 2 : STRATÉGIE D'IMPLÉMENTATION
═══════════════════════════════════════════════════════════════════

APPROCHE 1 : BOOTSTRAPPING PROGRESSIF
  1. Implémenter les constructions manquantes une par une
  2. Tester chaque nouvelle construction
  3. Compiler des sous-ensembles croissants du compilateur
  4. Atteindre progressivement l'auto-compilation complète

APPROCHE 2 : COMPILATION PAR SOUS-ENSEMBLES
  1. Identifier les fonctions les plus simples du compilateur
  2. Les compiler en premier (ex: gen-label, lisp-atom-p)
  3. Compiler progressivement les fonctions plus complexes
  4. Terminer par les fonctions de haut niveau

APPROCHE 3 : SIMPLIFICATION TEMPORAIRE
  1. Créer une version simplifiée du compilateur (compiler-mini.lisp)
  2. Retirer les fonctionnalités avancées non essentielles
  3. Compiler cette version simplifiée
  4. Utiliser le compilateur compilé pour compiler la version complète

RECOMMANDATION : APPROCHE 1 + 2 (HYBRIDE)
  • Implémenter les constructions manquantes prioritaires
  • Compiler d'abord les fonctions utilitaires simples
  • Progresser vers les fonctions complexes
  • Tester à chaque étape

PHASE 3 : PLAN D'ACTION DÉTAILLÉ PAS À PAS
═══════════════════════════════════════════════════════════════════

ÉTAPE 1 : PRÉPARATION (1-2 jours)
───────────────────────────────────────────────────────────────────
1.1 Analyser toutes les constructions utilisées dans compiler.lisp
    → Commande : grep -E "(defstruct|loop|member|append)" src/compiler.lisp
    → Créer une liste exhaustive des constructions manquantes
    → Classifier par priorité (critique/haute/moyenne)

1.2 Créer des tests unitaires pour chaque construction
    → test-defstruct.lisp
    → test-loop-advanced.lisp
    → test-multiple-value-bind.lisp
    → test-keyword-parameters.lisp
    → etc.

1.3 Établir une baseline de compilation
    → Essayer de compiler compiler.lisp avec le compilateur actuel
    → Noter les erreurs précises
    → Documenter les fonctions qui échouent

ÉTAPE 2 : DEFSTRUCT (2-3 jours)
───────────────────────────────────────────────────────────────────
2.1 Implémenter (defstruct name slots...)
    → Générer un constructeur (make-name)
    → Générer des accesseurs (name-slot)
    → Générer un prédicat (name-p)
    → Stocker la structure dans une hash-table globale

2.2 Tester avec des structures simples
    → (defstruct point x y)
    → (make-point :x 10 :y 20)
    → (point-x p)

2.3 Compiler compiler-env
    → La structure principale du compilateur
    → Tester tous les accesseurs

ÉTAPE 3 : LOOP AVANCÉ (3-4 jours)
───────────────────────────────────────────────────────────────────
3.1 Implémenter (loop for var in list ...)
    → Boucle sur une liste
    → Liaison de variable

3.2 Implémenter (loop for var from start to end ...)
    → Boucle numérique
    → Incrémentation automatique

3.3 Implémenter les clauses COLLECT et APPEND
    → (loop ... collect expr)
    → (loop ... append list-expr)
    → Accumulateurs implicites

3.4 Implémenter les clauses WHEN et UNLESS
    → (loop ... when condition collect expr)
    → Filtrage conditionnel

3.5 Implémenter DO
    → (loop ... do (side-effect))
    → Corps de boucle

ÉTAPE 4 : PARAMÈTRES AVANCÉS (2-3 jours)
───────────────────────────────────────────────────────────────────
4.1 Implémenter &optional
    → Paramètres optionnels
    → Valeurs par défaut
    → Tests de présence

4.2 Implémenter &rest
    → Paramètres variadiques
    → Liste des arguments restants

4.3 Implémenter &key
    → Paramètres nommés
    → Valeurs par défaut
    → Recherche par nom

4.4 Combiner les trois
    → (defun f (a b &optional c &rest r &key x y) ...)
    → Ordre et interaction corrects

ÉTAPE 5 : RETOURS MULTIPLES (1-2 jours)
───────────────────────────────────────────────────────────────────
5.1 Implémenter values
    → (values a b c)
    → Retourner plusieurs valeurs
    → Utiliser des registres multiples

5.2 Implémenter multiple-value-bind
    → (multiple-value-bind (a b c) (func) body)
    → Lier plusieurs valeurs retournées
    → Gérer le cas où moins de valeurs sont retournées

5.3 Implémenter values-list
    → (values-list '(1 2 3))
    → Conversion liste → values

ÉTAPE 6 : FONCTIONS DE LISTES (2-3 jours)
───────────────────────────────────────────────────────────────────
6.1 Implémenter member
    → (member item list &key test)
    → Retourne la sous-liste commençant par item

6.2 Implémenter assoc
    → (assoc key alist &key test)
    → Recherche dans une alist

6.3 Implémenter append
    → (append list1 list2 ...)
    → Concaténation de listes

6.4 Implémenter reverse
    → (reverse list)
    → Inversion de liste

6.5 Implémenter mapcar et mapc
    → (mapcar func list)
    → Application de fonction

6.6 Implémenter remove-if et find-if
    → (remove-if predicate list)
    → (find-if predicate list)
    → Filtrage

6.7 Implémenter some et every
    → (some predicate list)
    → (every predicate list)
    → Prédicats collectifs

ÉTAPE 7 : MACROS ET UTILITAIRES (1-2 jours)
───────────────────────────────────────────────────────────────────
7.1 Implémenter when et unless
    → (when test body...) → (if test (progn body...))
    → (unless test body...) → (if (not test) (progn body...))

7.2 Implémenter push et pop
    → (push item place)
    → (pop place)
    → Manipulation de piles

7.3 Implémenter incf et decf
    → (incf place &optional delta)
    → (decf place &optional delta)

7.4 Implémenter and et or (avec court-circuit)
    → (and a b c) → évaluation paresseuse
    → (or a b c) → évaluation paresseuse

ÉTAPE 8 : COMPILATION PARTIELLE (2-3 jours)
───────────────────────────────────────────────────────────────────
8.1 Identifier les fonctions utilitaires simples
    → gen-label
    → lisp-atom-p
    → lisp-list-p
    → vm-primitive-p

8.2 Compiler ces fonctions une par une
    → Tester chaque compilation
    → Charger dans la VM
    → Exécuter et vérifier les résultats

8.3 Compiler les fonctions de parsing
    → parse-lisp-expr (complexe!)
    → Décomposer en sous-fonctions si nécessaire

8.4 Compiler les fonctions de génération de code
    → compile-if
    → compile-let
    → compile-setq
    → etc.

ÉTAPE 9 : GESTION DES DÉPENDANCES (2-3 jours)
───────────────────────────────────────────────────────────────────
9.1 Analyser les dépendances inter-fonctions
    → Graphe de dépendances
    → Ordre de compilation correct

9.2 Résoudre les références croisées
    → Forward declarations si nécessaire
    → Table des symboles globale

9.3 Gérer les constantes et variables globales
    → defparameter → initialisation au chargement
    → Allocation mémoire pour les globales

ÉTAPE 10 : AUTO-COMPILATION COMPLÈTE (3-5 jours)
───────────────────────────────────────────────────────────────────
10.1 Compiler compiler.lisp au complet
     → Utiliser compile-and-load-file sur compiler.lisp
     → Résoudre les erreurs une par une
     → Documenter les problèmes

10.2 Charger le compilateur compilé dans une VM
     → Allouer suffisamment de mémoire
     → Initialiser les tables globales
     → Vérifier l'état de la VM

10.3 Tester le compilateur compilé
     → Compiler des programmes simples (fibonacci)
     → Compiler le loader
     → Vérifier la correction des résultats

10.4 Benchmark et optimisation
     → Mesurer les performances
     → Comparer avec le compilateur natif
     → Optimiser les points critiques

ÉTAPE 11 : BOOTSTRAPPING COMPLET (2-3 jours)
───────────────────────────────────────────────────────────────────
11.1 Le compilateur compilé compile compiler.lisp
     → Auto-compilation niveau 2
     → Vérifier l'idempotence

11.2 Comparaison des versions
     → Compiler avec compilateur natif : C1
     → Compiler avec C1 : C2
     → C1 et C2 doivent être identiques (ou équivalents)

11.3 Tests de régression
     → Tous les tests existants doivent passer
     → Le compilateur compilé doit être aussi capable

     $ clisp -x "(load \"src/compiler.lisp\") \
                 (with-open-file (s \"compiler-errors.txt\" \

                   (handler-case \
                     (compile-lisp '(load \"src/compiler.lisp\")) \

     → Créer AVANCEMENT-BOOTSTRAPPING.txt
