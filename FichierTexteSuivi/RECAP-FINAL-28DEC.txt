═══════════════════════════════════════════════════════════════════
PATTERNS D'IMPLÉMENTATION UTILISÉS
═══════════════════════════════════════════════════════════════════

1. DÉLÉGATION (DEFSTRUCT)
   Au lieu de générer du MIPS complexe, déléguer à Lisp via VM.
   Avantage : Implémentation 10x plus rapide.

2. EXPANSION (LOOP)
   Transformer LOOP en constructions simples (LET, WHILE).
   Avantage : Réutilise le code existant du compilateur.

3. HANDLES (DEFSTRUCT)
   Instances identifiées par entiers (handles).
   Avantage : Facile à manipuler depuis le code MIPS.

4. GENSYM (LOOP)
   Variables temporaires uniques pour éviter conflits.
   Avantage : Expansions sûres et correctes.

5. TESTS PROGRESSIFS
   Tester primitives → accesseurs → intégration.
   Avantage : Confiance et débogage facile.

6. MODULARITÉ
   Parser séparé, expander séparé, intégration séparée.
   Avantage : Code clair et maintenable.

LEÇONS APPRISES
═══════════════════════════════════════════════════════════════════

1. PRAGMATISME > PERFECTIONNISME
   Pour le bootstrapping, une implémentation rapide qui fonctionne
   vaut mieux qu'une implémentation parfaite mais longue à faire.

2. TESTS = VITESSE
   Investir dans les tests au début accélère le développement
   car on détecte les bugs immédiatement.

3. DOCUMENTATION = CLARTÉ
   Documenter au fur et à mesure évite de se perdre dans
   des projets complexes comme le bootstrapping.

4. RÉUTILISATION
   WHILE déjà dans le compilateur → on l'utilise !
   VM existe → on délègue !

5. EXPANSION > COMPILATION
   Transformer vers du code simple est souvent plus facile
   que de compiler directement.
