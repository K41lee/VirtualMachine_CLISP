1. REVERSE-LIST (44 instructions)
   ---------------------------------
   Fonction auxiliaire pour inverser une liste construite avec cons.
   
   Code Lisp:
     (defun reverse-list (lst)
       (let ((result nil))
         (dolist (elem lst)
           (setq result (vm-cons elem result)))
         result))
   
   Utilise: dolist, vm-cons, setq
   Nécessaire car vm-cons construit à l'envers (tête de liste)

2. RESOLVE-INSTRUCTION (90 instructions)
   ----------------------------------------
   Résout les symboles d'une instruction en adresses.
   
   Code Lisp:
     (defun resolve-instruction (instr labels-hash)
       (let ((result nil)
             (elem nil)
             (addr nil))
         (dolist (element instr)
           (setq elem element)
           (if (vm-symbolp elem)
               (progn
                 (setq addr (vm-gethash labels-hash elem))
                 (if addr
                     (setq elem addr)
                     nil))
               nil)
           (setq result (vm-cons elem result)))
         (reverse-list result)))
   
   Utilise:
     • vm-symbolp     : Tester si élément est symbole
     • vm-gethash     : Chercher adresse du symbole
     • vm-cons        : Construire nouvelle instruction
     • reverse-list   : Inverser la liste construite
     • dolist, if     : Contrôle de flux

   Logique:
     1. Itérer sur chaque élément de l'instruction
     2. Si c'est un symbole, chercher dans labels-hash
     3. Si trouvé, remplacer par l'adresse
     4. Sinon, garder le symbole original
     5. Construire nouvelle instruction avec éléments résolus

3. COLLECT-LABELS (92 instructions)
   -----------------------------------
   Collecte tous les labels et leurs positions.
   
   Code Lisp:
     (defun collect-labels (asm-code code-start)
       (let ((labels (vm-make-hash-table :test 'equal))
             (position 0)
             (first-elem nil))
         (dolist (instr asm-code)
           (if (vm-consp instr)
               (progn
                 (setq first-elem (vm-car instr))
                 (vm-hash-set labels first-elem 
                              (+ code-start position))
                 (setq position (+ position 1)))
               (setq position (+ position 1))))
         labels))
   
   Utilise:
     • vm-make-hash-table : Créer table des labels
     • vm-consp           : Tester si instruction est cons
     • vm-car             : Extraire premier élément (opcode/label)
     • vm-hash-set        : Stocker label→adresse
     • dolist, if         : Contrôle de flux
   
   Logique:
     1. Créer hash-table vide
     2. Position = 0
     3. Pour chaque instruction:
        - Si cons (vraie instruction):
          * Extraire premier élément
          * Stocker élément→(code-start + position)
          * Incrémenter position
        - Sinon: incrémenter position quand même
     4. Retourner hash-table

   Note: Stocke TOUS les premiers éléments (opcodes + labels)
         Le filtrage des :LABEL pourrait être ajouté si nécessaire

4. RESOLVE-LABELS (98 instructions)
   -----------------------------------
   Résout toutes les instructions en remplaçant symboles par adresses.
   
   Code Lisp:
     (defun resolve-labels (asm-code labels-hash)
       (let ((resolved-code nil)
             (instr nil)
             (first-elem nil)
             (resolved-instr nil))
         (dolist (instruction asm-code)
           (setq instr instruction)
           (if (vm-consp instr)
               (progn
                 (setq first-elem (vm-car instr))
                 (setq resolved-instr 
                       (resolve-instruction instr labels-hash))
                 (setq resolved-code 
                       (vm-cons resolved-instr resolved-code)))
               nil))
         (reverse-list resolved-code)))
   
   Utilise:
     • vm-consp             : Tester si instruction valide
     • vm-car               : Extraire premier élément
     • resolve-instruction  : Résoudre une instruction
     • vm-cons              : Construire liste résultat
     • reverse-list         : Inverser liste finale
     • dolist, if           : Contrôle de flux
   
   Logique:
     1. Liste vide pour code résolu
     2. Pour chaque instruction:
        - Si cons (vraie instruction):
          * Résoudre l'instruction (symboles→adresses)
          * Ajouter à la liste (avec cons = ajout en tête)
        - Sinon: ignorer
     3. Inverser la liste (construite à l'envers)
     4. Retourner code résolu

LOADER.LISP ORIGINAL:
---------------------
Fichier: src/loader.lisp

collect-labels:
  (defun collect-labels (asm-code code-start)
    (let ((labels (make-hash-table :test 'equal))
          (position 0))
      (dolist (instr asm-code)
        (if (and (listp instr) (eq (first instr) :LABEL))
            (setf (gethash (second instr) labels) 
                  (+ code-start position))
            (incf position)))
      labels))

Problèmes pour compilation:
  • make-hash-table    : Non-VM (pas de primitive)
  • listp, eq, first   : Non-VM
  • setf, gethash      : Non-VM (forme spéciale)
  • second             : Non-VM
  • incf               : Macro, compilable mais différent

resolve-labels:
  (defun resolve-labels (asm-code labels)
    (let ((resolved-code '()))
      (dolist (instr asm-code)
        (when (not (and (listp instr) (eq (first instr) :LABEL)))
          (let ((resolved-instr 
                 (mapcar (lambda (element)
                           (if (and (symbolp element)
                                    (gethash element labels))
                               (gethash element labels)
                               element))
                         instr)))
            (push resolved-instr resolved-code))))
      (nreverse resolved-code)))

Problèmes pour compilation:
  • mapcar avec lambda : Difficile à compiler (fonction d'ordre supérieur)
  • push / nreverse    : Macros spéciales
  • listp, eq, first   : Non-VM
  • symbolp, gethash   : Non-VM
