LIMITATIONS IDENTIFIÉES
═══════════════════════════════════════════════════════════════════════════════

1. VM - Pas de gestion mémoire dynamique
   Impact : Listes non stockables en mémoire
   Contournement : Manipulation de symboles délégués au Lisp hôte
   Pour corriger : Implémenter heap + GC (3-4 semaines)

2. DEFSTRUCT - Délégué à l'environnement hôte
   Impact : Structures non compilables en MIPS pur
   Contournement : Fonctionne en mode interprété
   Pour corriger : Implémenter constructeurs en MIPS (1 semaine)

3. Closures - Support limité
   Impact : Variables capturées non gérées complètement
   Contournement : free-variables analyse les dépendances
   Pour corriger : Implémenter environnements imbriqués complets

4. Optimisations - Basiques
   Impact : Code généré non optimal
   Exemples manquants :
     • Tail-call optimization
     • Inlining de fonctions simples
     • Constant folding avancé
     • Élimination de variables mortes

5. Auto-compilation - Partielle
   Impact : Compilateur ne peut pas s'exécuter compilé
   Raison : Limitation #1 (pas de listes en mémoire VM)
   Note : Le compilateur COMPILE correctement, mais ne peut pas EXÉCUTER
