1. OBJECTIF
═══════════════════════════════════════════════════════════════════════════════

Éliminer les dépendances aux fonctions d'ordre supérieur (MAPCAR, FUNCALL, APPLY)
dans compiler.lisp pour permettre l'auto-compilation.

Problème identifié :
  • compiler.lisp utilise MAPCAR dans free-variables
  • free-variables utilise des LAMBDA anonymes
  • Ces constructions ne sont pas (encore) compilables

Solution : Remplacer MAPCAR/LAMBDA par des fonctions récursives explicites

2.3 Contexte d'utilisation
──────────────────────────
Toutes ces utilisations sont dans la fonction free-variables qui analyse
les variables libres pour les closures. Cette fonction est exécutée par
le Lisp hôte pendant la compilation, mais pour l'auto-compilation, elle
doit être compilable elle-même.

3. SOLUTION IMPLÉMENTÉE
═══════════════════════════════════════════════════════════════════════════════

3.1 Fonctions helpers ajoutées
───────────────────────────────

A) extract-first-elements (list-of-pairs)
   Remplace : (mapcar #'first list-of-pairs)
   
   Implémentation :
   ```lisp
   (defun extract-first-elements (list-of-pairs)
     (if (null list-of-pairs)
         nil
         (cons (first (first list-of-pairs))
               (extract-first-elements (rest list-of-pairs)))))
   ```

B) extract-second-elements (list-of-pairs)
   Remplace : (mapcar #'second list-of-pairs)
   
   Implémentation :
   ```lisp
   (defun extract-second-elements (list-of-pairs)
     (if (null list-of-pairs)
         nil
         (cons (second (first list-of-pairs))
               (extract-second-elements (rest list-of-pairs)))))
   ```

C) flatten-clauses (clauses)
   Remplace : (mapcan (lambda (clause) clause) clauses)
   
   Implémentation :
   ```lisp
   (defun flatten-clauses (clauses)
     (if (null clauses)
         nil
         (append (first clauses)
                 (flatten-clauses (rest clauses)))))
   ```

D) extract-clause-bodies (clauses)
   Remplace : (mapcan (lambda (clause) (rest clause)) clauses)
   
   Implémentation :
   ```lisp
   (defun extract-clause-bodies (clauses)
     (if (null clauses)
         nil
         (append (rest (first clauses))
                 (extract-clause-bodies (rest clauses)))))
   ```

E) map-eval-constant-expr (exprs)
   Remplace : (mapcar #'eval-constant-expr exprs)
   
   Implémentation :
   ```lisp
   (defun map-eval-constant-expr (exprs)
     (if (null exprs)
         nil
         (cons (eval-constant-expr (first exprs))
               (map-eval-constant-expr (rest exprs)))))
   ```

5. EXEMPLES DE TRANSFORMATION
═══════════════════════════════════════════════════════════════════════════════

5.1 Exemple : extraction de premiers éléments
──────────────────────────────────────────────
Contexte : Parser LET bindings
Input : ((x 10) (y 20) (z 30))

AVANT (avec MAPCAR) :
  (let-vars (mapcar #'first bindings))
  → Appel à une fonction d'ordre supérieur

APRÈS (avec recursion) :
  (let-vars (extract-first-elements bindings))
  → (extract-first-elements '((x 10) (y 20) (z 30)))
  → (cons 'x (extract-first-elements '((y 20) (z 30))))
  → (cons 'x (cons 'y (extract-first-elements '((z 30)))))
  → (cons 'x (cons 'y (cons 'z nil)))
  → (x y z)

5.2 Exemple : aplatissement de clauses
───────────────────────────────────────
Contexte : Parser COND
Input : (((< x 0) 0) ((> x 10) 10) (t x))

AVANT (avec MAPCAN + LAMBDA) :
  (mapcan (lambda (clause) clause) args)
  → Crée une fonction anonyme qui retourne chaque clause

APRÈS (avec recursion) :
  (flatten-clauses args)
  → (append '((< x 0) 0) (flatten-clauses '(((> x 10) 10) (t x))))
  → (append '((< x 0) 0) (append '((> x 10) 10) (flatten-clauses '((t x)))))
  → ...
  → ((< x 0) 0 (> x 10) 10 t x)

5.3 Exemple : évaluation d'expressions constantes
──────────────────────────────────────────────────
Contexte : DEFCONSTANT avec calculs
Input : (+ 10 20 30)

AVANT (avec MAPCAR) :
  (mapcar #'eval-constant-expr '(10 20 30))
  → Applique eval-constant-expr à chaque élément

APRÈS (avec recursion) :
  (map-eval-constant-expr '(10 20 30))
  → (cons (eval-constant-expr 10)
          (map-eval-constant-expr '(20 30)))
  → (cons 10 (cons 20 (cons 30 nil)))
  → (10 20 30)
