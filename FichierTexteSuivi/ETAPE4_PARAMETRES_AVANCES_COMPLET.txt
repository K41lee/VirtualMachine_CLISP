1. OBJECTIF
═══════════════════════════════════════════════════════════════════════════════

Implémenter le support complet des paramètres avancés de Common Lisp :
  • &optional : Paramètres avec valeurs par défaut
  • &rest     : Collection d'arguments variables
  • &key      : Paramètres nommés (keywords)

Stratégie : EXPANSION (transformer en &rest + LET* + bindings)

Modification 4 - Nouvelle fonction compile-defun (lignes 3627-3662)
```lisp
(defun compile-defun (name params body parsed-params env)
  "Compile avec gestion des paramètres avancés"
  (let* ((has-optional (has-optional-params-p parsed-params))
         (has-key (has-key-params-p parsed-params))
         (needs-expansion (or has-optional has-key)))
    (if needs-expansion
        ;; Expanser puis compiler
        (let* ((expanded-defun (expand-function-with-advanced-params 
                                 name params body))
               (new-params (third expanded-defun))
               (new-body (cdddr expanded-defun))
               (new-parsed (parse-lambda-list new-params)))
          (compile-defun-standard name new-params new-body new-parsed env))
        ;; Compilation standard
        (compile-defun-standard name params body parsed-params env))))
```

Modification 5 - Support LET* (lignes 345-347, 3006-3008, 1458-1490)
```lisp
;; Parser
(let*
 (list :let* (first args) (rest args)))

;; Dispatch
(:let*
 (compile-let* (second parsed) (third parsed) env))

;; Implémentation
(defun compile-let* (bindings body env)
  "Compile LET* avec bindings séquentiels"
  (cond
    ((null bindings) ...)
    ((= (length bindings) 1) (compile-let bindings body env))
    (t
     ;; Imbriquer les LETs
     (let* ((first-binding (first bindings))
            (rest-bindings (rest bindings))
            (inner-let (append (list 'let* rest-bindings) body)))
       (compile-let (list first-binding) (list inner-let) env)))))
```


3. BUGS CORRIGÉS
═══════════════════════════════════════════════════════════════════════════════

Bug #1 : Récursion infinie dans compile-defun
──────────────────────────────────────────────
Problème : compile-defun s'appelait récursivement même sur les fonctions 
           expansées qui contenaient &rest
Solution : Vérifier uniquement &optional et &key, pas &rest simple

Bug #2 : LET vs LET* dans compile-defun-standard
─────────────────────────────────────────────────
Problème : (let ((a 1) (b (+ a 1)))) échouait car 'a' non défini
           LET évalue tous les bindings en parallèle
Solution : Utiliser LET* pour bindings séquentiels (ligne 3637)

Bug #3 : Gensym inconsistency dans lambda-list-expander
────────────────────────────────────────────────────────
Problème : expand-lambda-list-body appelait (gensym) plusieurs fois,
           créant des symboles différents
Solution : Créer gensym une fois dans expand-function-with-advanced-params
           et le passer en paramètre (ligne 234-237)

Bug #4 : LET* body splicing dans compile-let*
──────────────────────────────────────────────
Problème : (list 'let* rest-bindings body) créait ((expr)) au lieu de (expr)
Solution : (append (list 'let* rest-bindings) body) pour splicer (ligne 1487)

Bug #5 : QUOTE non supporté dans parser
────────────────────────────────────────
Problème : (quote x) parsé comme variable X au lieu de symbole 'x
Solution : Ajouter cas QUOTE dans parse-lisp-expr (ligne 341-344)

5. EXEMPLES D'EXPANSION
═══════════════════════════════════════════════════════════════════════════════

5.1 Exemple &optional
─────────────────────
Source :
  (defun foo (a &optional (b 10) (c 20)) (+ a b c))

Expansion :
  (defun foo (a &rest __rest__)
    (let* ((b (if (>= (length __rest__) 1) (nth 0 __rest__) 10))
           (c (if (>= (length __rest__) 2) (nth 1 __rest__) 20)))
      (+ a b c)))

Appels :
  (foo 5)      → a=5, b=10, c=20  → 35
  (foo 5 3)    → a=5, b=3,  c=20  → 28
  (foo 5 3 7)  → a=5, b=3,  c=7   → 15

5.2 Exemple &key
────────────────
Source :
  (defun bar (a &key (x 1) (y 2)) (+ a x y))

Expansion :
  (defun bar (a &rest __rest__)
    (let* ((x (getf __rest__ :x 1))
           (y (getf __rest__ :y 2)))
      (+ a x y)))

Appels :
  (bar 5)              → a=5, x=1, y=2  → 8
  (bar 5 :x 10)        → a=5, x=10, y=2 → 17
  (bar 5 :y 3 :x 7)    → a=5, x=7, y=3  → 15

5.3 Exemple &rest
─────────────────
Source :
  (defun concat (prefix &rest args) (cons prefix args))

Pas d'expansion nécessaire (déjà supporté par le compilateur)

Appels :
  (concat 'A 1 2 3) → (A 1 2 3)
  (concat 'X)       → (X)

5.4 Exemple combiné
───────────────────
Source :
  (defun complex-fn (a &optional b &rest r) (list a b r))

Expansion :
  (defun complex-fn (a &rest __rest__)
    (let* ((b (if (>= (length __rest__) 1) (nth 0 __rest__) nil))
           (r (nthcdr 1 __rest__)))
      (list a b r)))

Appels :
  (complex-fn 1)           → (1 nil ())
  (complex-fn 1 2)         → (1 2 ())
  (complex-fn 1 2 3 4)     → (1 2 (3 4))
