OBJECTIF
════════════════════════════════════════════════════════════════

Créer une version du parser qui utilise des comparaisons d'IDs 
numériques au lieu de CASE avec symboles, permettant ainsi 
l'auto-compilation complète.

PROBLÈME RÉSOLU :
  - parse-lisp-expr utilise CASE qui n'est pas compilable
  - CASE avec symboles → impossible de compiler en MIPS
  - Solution : COND + comparaisons = (compilable en SEQ MIPS)

IMPLÉMENTATION
════════════════════════════════════════════════════════════════

1. FICHIER : src/parser-with-ids.lisp (~260 lignes)
   
   FONCTION PRINCIPALE : parse-lisp-expr-with-ids(expr)
   
   DIFFÉRENCES AVEC parse-lisp-expr :
   
   Ancien (non compilable) :
   -------------------------
   (case op
     (+ (list :arithmetic '+ args))
     (if (list :if ...))
     ...)
   
   Nouveau (compilable) :
   ----------------------
   (let ((op-id (get-symbol-id (symbol-name op))))
     (cond
       ((and op-id (= op-id *+-id*))
        (list :arithmetic '+ args))
       ((and op-id (= op-id *if-id*))
        (list :if ...))
       ...))

2. STRATÉGIE HYBRIDE
   
   Pour les symboles pré-internés (59 symboles) :
   → Comparaison d'IDs avec = (compilable)
   
   Pour les symboles non internés :
   → Fallback symbolique avec EQ (pas encore compilable mais
     sera internalisé à l'étape 4)

ÉTAPE 4 : MODIFIER LE DISPATCHER (compile-expr)
  
  1. Remplacer CASE par COND dans compile-expr
  2. Comparer :type avec des IDs au lieu de symboles
  3. Exemple :
     
     Ancien :
     --------
     (case (first parsed-expr)
       (:arithmetic (compile-arithmetic ...))
       (:if (compile-if ...))
       ...)
     
     Nouveau :
     ---------
     (let ((type-id (get-symbol-id (symbol-name (first parsed-expr)))))
       (cond
         ((= type-id *arithmetic-id*) (compile-arithmetic ...))
         ((= type-id *if-id*) (compile-if ...))
         ...))

  4. Interne les types de nœuds (:arithmetic, :if, :defun, etc.)
