    │ (case symbol  │ ← Hash lookup non compilable

    │   (if ...))   │
    └───────────────┘
  
  Nouveau (compilable) :
    ┌───────────────┐
    │ (cond         │ ← Comparaisons entières SEQ MIPS

    │     ...))     │
