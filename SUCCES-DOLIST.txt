ARCHITECTURE TECHNIQUE
═══════════════════════════════════════════════════════════════════

SYSTÈME DE HANDLES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  • Hash-tables: Handles 1000+
    Stockées dans: *vm-hash-tables* (handle → hash-table Lisp)
  
  • Listes/Objets: Handles 5000+
    Stockées dans: *vm-lisp-objects* (handle → objet Lisp)
  
  • Avantage: VM manipule des entiers, Lisp gère la complexité

DOLIST AVEC HANDLES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1. list-expr évaluée → handle dans $V0
  2. Handle stocké dans $S1 (temp-list)
  3. Boucle:
     a. TYPE-CHECK consp $S1 → 0 si vide, sortir
     b. LIST-CAR $S1 → élément dans $V0, handle si nécessaire
     c. Élément stocké dans $S2 (var)
     d. Corps de la boucle exécuté
     e. LIST-CDR $S1 → $S1 (liste restante)
     f. Retour au début

collect-labels original:
  (defun collect-labels (asm-code code-start)
    (let ((labels (make-hash-table :test 'equal))
          (position 0))
      (dolist (instr asm-code)
        (if (and (listp instr) (eq (first instr) :LABEL))
            (setf (gethash (second instr) labels) 
                  (+ code-start position))
            (incf position)))
      labels))

Adaptations nécessaires:
  1. make-hash-table → vm-make-hash-table        ✓ Fait
  2. dolist → Utilise TYPE-CHECK/CAR/CDR         ✓ Fait
  3. listp → vm-listp (TYPE-CHECK listp)         ✓ Disponible
  4. first → vm-car                              ✓ Disponible
  5. second → vm-car + vm-cdr                    ✓ Disponible
  6. gethash/setf → vm-gethash/vm-hash-set       ✓ Fait

Code adapté:
  (defun collect-labels-vm (asm-code code-start)
    (let ((labels (vm-make-hash-table :test 'equal))
          (position 0))
      (dolist (instr asm-code)
        (if (and (vm-consp instr) 
                 (eq (vm-car instr) :LABEL))
            (vm-hash-set labels 
                        (vm-car (vm-cdr instr))
                        (+ code-start position))
            (setq position (+ position 1))))
      labels))
